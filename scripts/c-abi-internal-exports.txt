# c-abi-internal-exports.txt — extern-C exports of libmadc.so that are
# INTERNAL: not part of the C ABI (docs/adr/0003-c-abi-stance.md), but
# classified so scripts/check-c-abi-surface.sh can prove the surface
# complete. Field 1 = symbol (exact match); the rest of the line is the
# disposition. A NEW export belongs in madc_api.h (ABI), under a
# machinery prefix (__madc_*), or here WITH a disposition — never
# unlisted.
#

# forest ledger packs symbol names, so a rename has artifact blast
