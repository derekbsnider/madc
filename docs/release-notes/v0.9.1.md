# Release v0.9.1 — 2026-04-24

SMAUG Phase F porting surfaced a cluster of latent code-generation and
parsing bugs that had been silent in the existing test suite because
many tests lacked per-test `.expect` fixtures. This patch release rolls
up eight commits of bug fixes — most notably a ternary operator that
silently dropped its result when assigned to a local `int`, and a
shared-string-literal caching pattern that emitted the literal's
address load only on the first branch that referenced it.

## Highlights

- **Ternary now writes merged result to Mem destinations** — every
  `int r = cond ? a : b;` was silently producing 0 because
  `TokenTerQ::compile()` only honoured Gp-register caller destinations.
- **Shared string literals re-emit their address load on every access** —
  `printf("hello\n")` appearing in two switch cases used to print on
  the first matching case and read garbage from an uninitialised
  spill slot on the second.
- **Unary `-` initializer `int a = -2;` now stores -2** — two
  cooperating bugs (TokenNeg mirror-back missing + parseExpression's
  conditional-end-at-`)` skipping the operator-stack flush) combined
  to drop the negation.
- **C function-pointer cast `(RET (*)(PARAMS)) expr`** — the cast
  parser now recognises `(*)` after the return type and builds a
  `DataDefFPTR`, unblocking qsort-style calls.
- **Case values parse as constant integer expressions** — `case EOF:`,
  `case (1+1):`, `case 'a':` all go through `parse_constant_integer_expression`,
  and switch now sign-extends narrow signed expressions into the
  64-bit compare register.
- **`map` / `vector` / `set` / `list` as identifiers at statement
  position** — `MAP_DATA *map; map->vnum = …;` in SMAUG's `db.c`
  now parses when these keywords aren't followed by `<`.
- **Unary `*` on postfix chain** — `*p->name == '$'` now parses via a
  new `parsePostfixChain()` helper instead of greedily consuming the
  trailing `==` as part of the deref target.
- **`(*pp)->field` fallthrough** — the `->` handler's `ttMember`
  branch now falls through to the expression-backed pointer path when
  the LHS is a `TokenDeref` / `TokenDerefExpr`, fixing qsort-style
  double-pointer comparators.
- **`DIR` typedef in embedded `<dirent.h>`** — opaque directory-handle
  typedef so `DIR *dp;` parses in SMAUG-style C code.
- **safemov(Gp, Gp) emits movsxd/movsx for signed widening** — was
  emitting unconditional `movzx`, which zero-extended negative values.
