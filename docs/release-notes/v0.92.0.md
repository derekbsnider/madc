# Release v0.92.0 — 2026-08-20

Bare `cout << value` with zero includes, and `std::format` /
`std::print` / `std::println` as always-included madc intrinsics.

- **`cout << value` needs no includes.** `madc::value` is an inherent
  madc-mode type (owner law); its stream inserter was header-gated in
  `<ns_madc>` behind the ostream include guard, so the bare script
  `var test = "hello"; cout << test << endl;` failed and include ORDER
  could compile the declaration out. The declaration now rides a
  compiler-owned fragment injected once at the completion of whichever
  include first defines the ostream guard — guard-keyed (so
  `<fstream>`/`<sstream>` arm it), top-level completions only, madc
  dialect only; strict C/C++ stay pristine.
- **The C++23 formatting surface is part of madc** — zero includes,
  zero header parse, never a libstdc++ `<format>` in sight:
  `std::println("x={} y={:.3f}", x, y)` just works in a bare script.
  The compiler is the implementation: literal format strings are
  validated at COMPILE time by the same strict-C11 engine the runtime
  uses (one grammar owner, in the AOT ledger so `-static` images carry
  it), making invalid strings compile errors — the C++23 contract with
  no consteval machinery. Every emission behavior is pinned
  byte-for-byte to real libstdc++ std::format by 1430 generated oracle
  rows (g++ 13.3): shortest-round-trip float defaults (fixed wins
  length ties), bit-exact hex floats, byte-string width/precision,
  sign-then-prefix negative hex. `std::format` returns a real
  `std::string`; a `value`/`var` argument formats as its contained kind.
- **Front-end fix flushed out by the arc:** a cast applied to a
  paren-less sizeof (`(long long)sizeof chunk`, valid C89) resolved
  `sizeof` as a variable. Fixed at the cast-operand dispatch;
  gcc/clang oracle.
- One libstdc++ 13 defect found and excluded with evidence:
  `{:#.0f}` of DBL_MAX returns a corrupt buffer (leading NUL, shifted
  digits); the engine keeps printf's correct output.

Boundaries (docs/plans/2026-08-19-std-print-format-intrinsics.md):
std::vformat / runtime format strings are phase 2; `var s =
std::format(...)` awaits value's std::string-ingestion overload;
width-from-argument, locale L, chrono/ranges, wide output and user
formatter<T> are refused by name.
