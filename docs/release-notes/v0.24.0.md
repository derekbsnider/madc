# Release v0.24.0 — 2026-05-28

Native C99 `_Complex` support implemented directly in our c2mir fork,
replacing the struct-based workaround. All 12 `_Complex` tests now pass,
bringing transpiler parity to 88.2% (419/475).

- Native `_Complex double/float/long double` in c2mir (13 commits, 0 regressions)
- Complex constant folding for global initializers (`_Complex v = 3.0 + 1.0iF;`)
- Complex-to-scalar cast extracts real part per C99 6.3.1.7
- `__real__`/`__imag__` as first-class Gecko grammar operators
- Removed `struct __madc_c*` workaround (-302 lines)
- Transpiler emits raw `_Complex` types and imaginary literals directly
- All 12 `_Complex` tests passing (was 0 before this release)
- Test parity: 419 passed, 56 skipped (was 410/65)
