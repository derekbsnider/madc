# Release v0.58.0 — 2026-07-28

The `<string_view>` release: libc++'s `<string_view>` now compiles **and
runs** end-to-end under `-stdlib=libc++` (the canonical probe prints "5 e"),
completing the P2.2 burn-down of the second-stdlib-flavor plan. The final
four front-end defects were all gaps in madc's own generic C++ machinery —
non-type template parameters, merged `>>` handling, the comma operator, and
aggregate initialization — so both stdlib flavors (and plain C++ programs)
get the hardening. The pre-merge packed battery then surfaced two forest
(freeze/thaw) gaps, fixed as format v34. Suite 784 → 792, green in every
lane.

- **Non-type template parameter defaults + SFINAE overload selection** —
  libc++'s defaulted-pointer-NTTP idiom `__enable_if_t<_Cond, int>* =
  nullptr` works end-to-end: declarator suffixes on NTTP types, folded
  value defaults, per-param constraint capture re-evaluated at instantiation
  (real substitution-failure rejection), and value-distinct instantiation
  identities (`g<int,3>` vs `g<int,7>`).
- **Merged `>>` at a template-id flush against the enclosing close** —
  `foo<pair<T,U>>` as a template argument no longer swallows the enclosing
  argument list's close.
- **C++ comma-operator returns** — `return _LIBCPP_ASSERT(...), value;` is a
  comma expression, not madc's dialect multi-return; the dialect lane is now
  gated to madc-dialect user code, and reference-returning comma chains
  lower correctly.
- **Braced aggregate init on class-promoted structs** — `SV s = {"hi", 7};`
  on a struct with methods initializes memberwise ([dcl.init.aggr]) instead
  of being silently dropped.
- **Forest v34 (freeze/thaw)** — declaration-only member templates (the
  `_S_test` SFINAE shape) now freeze their dependent return-type range, so
  a thawed `decltype(_S_test<A,B>(0))` resolves instead of collapsing to a
  64-bit integer; and the stdlib *flavor* joined the producer-config
  identity, so a libstdc++-parsed forest never binds into a
  `-stdlib=libc++` compile (it live-parses instead). Both were
  LOADED ≠ parsed silent wrong answers caught by the packed battery lane.
- **New gates:** `testnttpsfinae`, `testcommareturn`, `testaggrclassinit`
  integration tests; `forest_bind_gate.sh` grew `[declonlymt]` and
  `[flavorgate]` cases.
- MIR fork unchanged (1.0-madc.0.52.0).

Next on the libc++ track: the stdlib-flavor ABI switch (P2.3) to unlock the
native exe/obj lanes for cross-flavor tests, then `<string>` end-to-end
(P2.4).
