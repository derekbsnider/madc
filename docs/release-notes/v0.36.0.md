# Release v0.36.0 — 2026-07-20

The native-compiler release. The CIR → c2mir → MIR pipeline now goes all the
way to disk: `madc -c` emits real ELF relocatable objects and `madc -o` emits
runnable ELF executables **assembled entirely by MIR** — no gcc, no ld, no
crt files — restoring (and exceeding) the asmjit-master native-output
capability on the modern backend. The same arc delivered source-level gdb
debugging of JIT'd programs and a set of correctness rungs that keep the
gcc-torture promote gate green.

Highlights:

- **`madc -c x.mad`** — a standards-conforming ELF `.o` from MIR's new
  object-capture mode (gen captures code + a complete relocation ledger
  instead of publishing JIT memory). Validated by compiling, linking, and
  running the entire fork corpus through the object lane: 1139/0.
- **`madc -o prog x.mad`** — a complete dynamic executable emitted directly:
  synthesized `_start` → `__libc_start_main`, `PT_INTERP`/`.dynamic`
  (`DT_NEEDED`, `DT_RUNPATH`), SysV `.hash`, eager `.rela.dyn`; no
  PLT/GOT needed thanks to MIR's slot-based call model. External toolchains
  are used only as test oracles, never in the product path.
- **`madc -shared`** emits `.so` output (interim lane; direct `ET_DYN`
  emission and PIC are the next rungs).
- **gcc/clang CLI vocabulary** — `-c` / `-o` / `-shared`, with
  `--emit-object` / `--emit-executable` kept as aliases.
- **The native-executable test lane is live**: every green JIT test also
  compiles to an executable, runs, and must match — 709/729 passing on day
  one (the remainder are classified: `--project` per-TU objects, two
  structurally JIT-only tests, one small deref cluster).
- **`madc -g`** — full source-level gdb on JIT'd `.mad` programs (pending
  `break file:line`, named typed frames, `info locals` in any frame,
  `.debug_frame` CFI for reliable backtraces).
- **Component-correct GNU integer `_Complex`** with gcc semantics (including
  Smith division in integer arithmetic), lifting three torture skips.
- **Library API at every layer** (owner directive): all AOT features are
  reachable through libmir (`MIR_gen_*`) and c2mir (`c2mir_get_native_*`)
  APIs — `c2m -fobject` and madc's CLI are thin consumers.
- gcc-torture: 1614 passing, promote-gate threshold held, failset
  name-identical across the whole arc; fulltest and packed suite 729/0/0/13
  throughout.
