# Release v0.98.0 — 2026-09-06

madc builds, freezes and runs its full test suite on macOS itself. The
darwin-host port put the whole battery on GitHub's arm64 and Intel mac
runners, and what it found drove this release: a C++ front-end wave of
sixty-odd fixes from the standard's text (templates, nested classes,
namespaces, the Itanium class-call ABI, libc++'s spelling of the
library — `<list>` included), the MIR aarch64 backend brought to x86-64
parity (128-bit SIMD, the AAPCS64 and Apple ABIs), and a vector calling
convention that is now gated against the platform compilers instead of
against itself. Underneath, the default install became the packaged
shape — a thin `madc` CLI over a shared `libmadc` that carries the
frozen forest — with all six release assets built by CI, and the owner
law that every platform lane's full suite gates a master release.

Highlights:

- **The full suite on macOS, both architectures**: `darwin-probe.yml`
  runs `run_tests.sh --exe` on `macos-14` (arm64) and `macos-15-intel`;
  twelve measured dispatches — each wave's residue predicted before the
  run — took arm64 from 202 failures to the libc++ `<list>` trio, closed
  here — arm64 1293/0/0TO/24skip, Intel 1294/0/0TO/23skip. `MADC_FAIL_DETAIL=N` makes the runner carry its own
  diagnosis; `.darwin_skip` / `.darwin-<arch>_expect` / `.win64_expect`
  fixtures replace per-test branches.
- **C++ front end — the darwin wave**: `<` opens a template-argument-list
  by NAME LOOKUP ([temp.names]/3); deduction from two arguments must
  agree and a SFINAE-constrained constructor is a candidate only when
  its constraint holds (`std::string(20, 'x')` on libc++); dependent
  non-type defaults fold; `namespace fs = std::filesystem;`; nested
  classes declared then defined out of line (`struct A::B : A {}`,
  `P::I &P::I::next()`, `sizeof(O::N)`); a member template hides a
  same-named global; hidden-friend operator templates; `wchar_t` /
  `char16_t` / `char32_t` distinct; `std::cout << char_array` and
  `std::wcout << L"x"` print text, not garbage or a pointer.
- **Class-call ABI (Itanium "non-trivial for the purposes of calls")**:
  a by-value class parameter is the callee's OWN object, passed by
  invisible reference and destroyed by the caller; ONE predicate decides
  both call directions (`__retbuf` return, invisible-reference
  parameter); `return local;` and `return param;` move; `B d(std::move(a))`
  selects the move constructor. Three silent-wrong-answer classes and
  one double free, each with a g++/clang++-oracled reducer.
- **libc++ `<list>` and the stdlib-flavor boundary (wave 12)**: a
  template-id named as a template ARGUMENT while a class body is in
  flight instantiates after that body completes ([temp.inst]/1) —
  `std::list` works under libc++; `B::x` inside a method is the member
  of `*this` (was the constant 0); `println("{}", s)` and `cout << value`
  work when the script's stdlib flavor is not the host's; the carrier
  gains `is_boolean`/`is_integer`/`is_real`/`is_bytes`/`is_instance`,
  `data()`, and `const` readers; a dependent member template-id is one
  placeholder per argument list (the darwin pack's `<list>` failure: two
  `rebind_alloc<...>` uses shared one placeholder — found and verified on the
  build container with the cross madc freezing and parsing the pack).
- **MIR aarch64 at x86-64 parity**: `__int128` returns in `x0:x1`, a
  `_Complex` argument is an HFA in FP registers, registers canonicalize
  under `MIR_LD_IS_D`, the `va_list` shape is a target property (Apple's
  `char *`); 128-bit vectors are Q-register values with NEON lane
  arithmetic, compares and shifts (S1–S5, every encoding from an
  assembler oracle, `third_party/mir/aarch64-neon-encodings.md`).
- **The vector and stack-argument calling conventions, gated against gcc /
  clang / Apple clang / mingw-gcc**: one c2mir predicate makes a 128-bit
  vector a register-class value at every call boundary (it was garbage
  through `...` and a block on aarch64), 16-byte stack slots are 16-byte
  aligned, Apple packs sub-8-byte non-variadic stack arguments, win64
  passes a vector by reference, plain `char` is unsigned on
  aarch64-linux; `scripts/vector_abi_gate.sh` (28 lines, one side
  compiled by the host compiler) is in fulltest.
- **The packaged install shape**: plain `./configure` builds the thin CLI
  against `libmadc.so.0` carrying the forest (+0.4 ms cold start,
  measured); `madcide` ships compiled in the Linux and Windows packages;
  a relocatable linux tarball; `libmadc-0.dll` named for what it is; the
  C ABI classified and gated (ADR 0003: C ABI stable, C++
  version-locked); install-then-run gates on the shipped bytes;
  `release.yml` builds all six assets, the two macOS tarballs natively.
- **C, headerless and strict**: an undeclared variadic libc call adopts
  the pack's REAL prototype (112 zero-include `printf` scripts on Apple
  arm64 printed addresses); C23 `_FloatN` suffixes lex as one literal;
  the GNU vector extension subscripts any vector expression and types
  comparisons as gcc does; c2mir's `extern` + initializer and
  anonymous-union alias class (upstream mir#472 / #473, reported with
  reducers by **aardappel**); `-w` inhibits warnings.
- **Target properties, not baked constants**: `long double` size and
  alignment (8/8 on Apple arm64), the darwin `long`/`long long`
  identity, `__builtin_nansl`'s pattern, the `va_list` shape — each
  from the compiler that builds madc for the target.
- **Process**: OWNER LAW 2026-09-04 — every platform lane's FULL suite
  gates a master release (`lane_ledger.sh check --release`: libc++
  flavor, darwin suite on both arches, genuine Windows); a platform
  failure is fixed or formally skipped with a reason. Wave validation:
  linux JIT 1308/0/9skip, EXE+OBJ 1249/0, packed 1308/0, headerless
  1274/0/43skip; libc++ JIT 1303/0/14skip, EXE 1244/0, OBJ
  1244/0; wine64 1251/0/0TO/66skip; c-testsuite 220/220; darwin arm64
  1293/0/0TO/24skip / Intel 1294/0/0TO/23skip; owner Mac 1293/0/0TO/24skip; genuine
  Windows 1253/0/0TO/64skip.
