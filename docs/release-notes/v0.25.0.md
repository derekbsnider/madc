# Release v0.25.0 — 2026-05-30

The CIR backend becomes madc's sole code path, and the headline milestone
lands: **SMAUG 1.8 (~158k LOC C89) boots, runs as a live server, and is
playable** through `cir_node → c2mir → MIR → JIT`. A connected client can
create a character, navigate the world, and fight — the Newgate room-109
serpent fight runs without crashing. This release integrates the 145-commit
`feature/cir-node` branch (asmjit JIT and the Gecko parser/transpiler removed)
plus the runtime fixes that took SMAUG from "won't link" to gameplay.

## Highlights

- **SMAUG 1.8 boots to a live server** (`Realms of Despair ready … port 4000`)
  and is playable: character creation, world navigation, and combat all run.
- **CIR is the sole backend.** `madc parser → cir_node (MC11-IR) → c2mir → MIR`;
  asmjit and Gecko are gone. MC11-IR is set in stone (derives from c2mir
  `node_t`, carries originating tokens + parse tree + source positions).
- **fn-ptr-typedef rendering** — function typedefs/members/vars/params render
  from the retained signature instead of erasing to `long`; the implicit `*`
  is added at emit time so the expression parser's fn-ptr-call detection keeps
  working (`49b79a1`, `7924e42`).
- **extern set only at variable creation** — a defined global can no longer be
  demoted to a declaration by a redundant `extern` (`62577a8`).
- **varargs lowered to the c2mir intrinsic** — `va_start(ap,last)` →
  `__builtin_va_start(ap)`, fixing a `reg_save_area` corruption in large frames
  (`2fbe5f0`).
- **switch `default` case emitted** — `translate_switch` had silently dropped
  every `default:` (`4011d95`).
- **strcmp family declared `int`** — undeclared comparison libc fns defaulted to
  a `long` return, so negative results read as huge positives and binary
  searches over sorted tables always failed; this broke SMAUG's skill lookup
  (79 skills) and crashed combat. Now declared `int` (`ac16d07`).
- **JIT-symbolizing crash handler** — madc's SIGSEGV backtrace resolves
  MIR-generated frames to `func+0xoff [JIT]`; the first brick of a madc-native
  debugger (`25c731a`).
- **Earlier in the cycle:** array/pointer type-erasure family, 2D-array init,
  switch pre-case declarations, abstract parameters as `N_TYPE`, and the real
  System V `va_list` ABI drove SMAUG from **159 → 0** c2mir check errors.
- **Integration: 316 → 325** (CIR backend). The remaining failures are the CIR
  coverage worklist.

## Dependency note

madc now builds against the **madc MIR fork** —
[github.com/derekbsnider/mir](https://github.com/derekbsnider/mir), branch
`feature/complex-support` — at `/workspace/mir`, **not** upstream MIR. The fork
carries native C99 `_Complex` support and the c2mir fixes the CIR backend
relies on. Clone and `make` it before building madc:
`git clone -b feature/complex-support https://github.com/derekbsnider/mir /workspace/mir`.
