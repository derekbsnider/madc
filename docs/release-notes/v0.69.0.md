# Release v0.69.0 — 2026-08-07

The release lane is restored and script mode is complete. Since Aug 1,
`make release` had silently failed at the forest-pack verify — programs
compiled against the full packed 19-header forest split template
instantiation identities between the freezing parse and bound consumers,
leaving the packed suite at 982/15 and no v0.68.0 release binary in
existence. Nine root-cause fixes bring the packed suite to **999/0**
(identical to the live lane), and top-level `defer` / `:=` join the
synthesized script-mode main.

Highlights:

- **The release lane is green again**: `make release` rc=0 including the
  forest-pack verify (242 units, bind cache == no-cache); the packed
  suite runs **999/0/9skip** against the stripped -O2 `bin/madc-release`.
- **Nine freeze/thaw identity fixes** (#20): canonical scalar dds in
  template-argument bindings, recorder flavor-twin pinning, thaw-side
  overload-set rejoin, using-import restore order parity, the
  builtin-only typedef-alias guard, namespace-faithful despaced lookup,
  best-effort default-arg re-derivation, member-access copied-call
  recovery, and auto-include injection inside the restore window.
- **Script mode completes** (#16, #18): top-level `defer` and top-level
  `a, b := f()` multi-return receivers are real statements of the
  synthesized main.
- **A cross-TU freeze-consumer gate** joins `fulltest` — it freezes a
  small corpus and binds three consumers against it, closing the gate
  class that let this regression live unseen: prior forest gates only
  ever froze each test's own translation unit.
- **The wall-fall battery caught its own regression**: the first cut of
  one fix collapsed glibc's `jmp_buf` constructed typedef and broke
  every `-static-libmadc` try/catch image; it was bisected in four
  container-worktree builds and narrowed before anything shipped.
- Release-HEAD battery: fulltest **999/0/0TO/9skip**, libc++ lane
  **995/0/13skip**, native EXE/OBJ **978/0**, packed **999/0/9skip**.
