# Release v0.101.0 — 2026-10-03

**madc has a REPL, and madcide becomes a teaching IDE.** Run `madc` with no
program file and you get an interactive C/C++ session in the spirit of Julia
and IPython: each entry's definitions carry into the next, results are named
(`ans`, `_`, `_N`), and `%whos`, `%type`, `%help` and `?name` answer questions
about what you have built so far. madcide, the editor, grows a plugin system,
and its first product built on it is **Chthonia**, a teaching profile modelled
on Thonny. The release also carries the B-series burn-down, which fixes silent
wrong answers first, and two new release safeguards: a Linux Homebrew bottle
and an archive of every released binary.

## Highlights

- **The REPL.** `madc` alone opens it; `madc -i file` runs a file and then
  keeps its names. An interactive entry is its own parser mode: statements
  run, definitions persist, an entry that cannot compile or link is refused
  without ending the session, and a crash inside an entry no longer ends madc.
  Line editing, history and Tab completion work on a terminal.
- **Sessions in their own process.** `madc::session_*` drives a session from
  the dialect. Load and run replies carry diagnostic rows, language switching
  is per session, and Stop interrupts a running entry.
- **Chthonia, the teaching IDE.** Chthonia is madcide with its teaching
  profile: a REPL pane, a Variables view, Run ▸ Language…, F5 diagnostics in
  the Problems pane, and Thonny's key style by default. The name mixes the
  projects it learns from (Thonny for the IDE, Julia for the REPL) with a
  C for C/C++ and an h for helper; say it "THO-nee-ah".
- **madcide plugins.** Plugin libraries load through an API table and can
  contribute commands, views, event handlers and toolbar rows.
  `--build-plugin` builds them; they also run from source in-process or in a
  forked child, and `madc -shared` emits a Windows DLL so they load there too.
  A program name selects its profile bundle.
- **Editing.** madcide gains selection and the platform clipboard; key styles
  for JOE, Emacs (region, kill ring, Meta), Thonny and VS Code, with modifiers
  on every key, chosen and saved per user; UTF-8-aware columns.
- **Correctness burn-down.** Silent wrong answers came first: value categories
  and rvalue references, out-of-line overloads that bound the wrong body,
  member pointers, partial specializations, atomics, constructor
  initialization, bit-field layout including the Microsoft rules, `volatile`
  carried through typedefs, and multi-TU template instance naming. Each fix
  ships a reducer checked against gcc and clang.
- **Linux Homebrew bottle.** The formula builds, bottles, pours and tests on
  Linux; the macOS bottle follows in a later release.
- **Every release binary is kept.** `scripts/release_bins.sh` archives each
  released `madc-release` since v0.72.0 with its library, and `run <test>`
  shows a test's history across releases, which is how this release's
  regressions were told apart from older defects.
- **One seam battery.** Tier 3 is `scripts/seam_battery.sh`: the full suite
  once, on the shipped -O2 packed binary with no headers on disk, then the
  smaller on-disk, Windows, native-artifact and cross-build stages,
  cheapest first.
