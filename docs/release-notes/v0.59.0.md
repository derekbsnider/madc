# Release v0.59.0 — 2026-07-29

The trait-engine release. gcc13's `__and_/__or_/__not_` SFINAE machine and
the constructible/assignable trait family now fold correctly in every lane —
live parse, dependent-parse materialization (vector reallocation picks the
same move/copy lane g++ does), and freeze/bind (a capture parse can no longer
bake a wrong trait constant into a frozen pattern, forest format v35). Every
fix matches g++ 13 AND clang++ 18 on an oracle-verified test; the suite grows
792 → 796, green in all lanes.

Highlights:

- `__or_fn`/`__and_fn` SFINAE correct end-to-end: [temp.deduct]/8 unused-arg
  validation (a failing concrete arg is a substitution failure even for args
  the alias target never names), pack-aware by-key returns, and baked-ref
  trait args (`DataDefREF` unwraps into the trait evaluator's flags).
- `__is_constructible` / `__is_nothrow_constructible` builtins, tri-state
  with honest declines — gcc13 type_traits uses them unconditionally.
- `noexcept` reaches the parser: the lexer re-lexes unconditional `noexcept`
  as `throw()`; `FuncDef::noexcept_spec` rides clones, method patterns, and
  the forest.
- Variadic bases really instantiate at the base-clause resolution:
  `__move_if_noexcept_cond : __and_<...>::type` folds, and
  `_M_realloc_insert` takes the move_iterator lane g++ takes (the earlier
  class-wide arming that broke the c++20 legs was bisected out and replaced
  with base-specifier-scoped arming).
- Template-instantiation keys distinguish pointer from reference arguments
  (`X<int*>` ≠ `X<int&>`; `*`→`P`, `&`→`R`) — forest v35, `testtplargkey`.
- Trait folds refuse dependent type arguments: the freeze-time capture parse
  had folded `__is_assignable(_Tp,_Up)` to a constant false and frozen it as
  is_assignable's base (packed-lane `testtraitassign`); new bind-gate case
  `[traitfold]`.
- Absent-trailing-pack elisions in both body-substitution lanes, dropped
  defaulted/deleted ctor recording, dependence-classifier scope fixes
  (member-after-`::`, enclosing-namespace chain via
  `namespace_chain_datatype`), lazy body stashing for system-header methods
  at instantiation depth, and env-gated `MADC_XTEST_VRI_DEBUG` diagnostics.

Suites: fulltest 796/0/0/9; `--exe` 779/0; `--obj` 779/0; packed arbiter
796/0/0/9; forest bind + selfexe gates green. MIR fork unchanged
(1.0-madc.0.52.0).
