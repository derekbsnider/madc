# Release v0.35.0 — 2026-07-14

The small-binary + family-D release. The packed release binary drops from
101 MB to **9.26 MB** — under the 10 MB product target — via per-segment zstd,
a new snapshot-v2 segment-transform vocabulary, and owner-approved intern-spine
pack compression, while bound compiles keep their lazy per-unit decode. The
family-D forest drain-gap campaign lands alongside it: pack drops fall
483 → 308, function-local class hoists gain stable deterministic identities,
and the ladder's live parser/CIR correctness fixes ship with dedicated tests.

## Highlights

- **Packed release binary 101 MB → 9.26 MB (blob 3.8 MB).** Per-segment zstd
  (level 15 for the appended pack, codec default for dev freezes — budgeted
  against the box's per-process CPU cap).
- **Snapshot format v2 — segment transforms.** The per-segment `flags` field
  becomes a reversible byte-stream transform vocabulary: CHILDREN u32-delta
  (1.68 → 0.09 MB stored) and RECORDS byte-plane at the record stride
  (2.05 → 0.89 MB stored), decoded through a 16×16 SSE2 tile transpose. The
  planned ZDICT dictionary approach was measured on the real pack frames and
  refuted before implementation.
- **Intern-spine pack compression (owner-approved trade):** the three intern
  blocks shrink 3.74 → 0.81 MB; consumers rebind through the owned-buffer
  fallback (~7 ms once per process). Dev freezes keep zero-copy binds.
- **Build now requires libzstd-dev** (`--without-zstd` is the loud opt-out;
  the old silent zlib fallback is how raw storage regressed unnoticed).
- **Family-D drain-gap campaign merged:** pack drops 483 → 308 (reducer) /
  346 (release pack) across rungs 6–11 plus the local-class carry.
- **Stable function-local declaration identity:** hoisted local classes, GNU
  nested functions, and dependent-pattern functions are named by enclosing
  emission symbol × source name × per-body ordinal — no more parse-order
  hoist counters leaking into frozen state.
- **Ranked-callee operand typing (systemic CIR fix):** call operands type by
  the rank-resolved callee's return type, not an arbitrary late-bound overload
  set member — fixes `return *this = std::move(x)` shapes everywhere at once.
- **Live correctness ladder:** `*this = v` and `*this->ptr() = c` assignment
  parsing, stream manipulators (`cout << hex << 255`), chained arrow method
  calls, full exception-declaration grammar in catch parameters, contextual
  `operator bool`, transitive virtual-base subobject offsets.
- **Suites:** fulltest **695/0/0/16**, packed release suite **695/0/0/16**
  (blob presence verified), forest bind gate 18/18 (bound == live == g++).
