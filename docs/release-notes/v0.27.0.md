# Release v0.27.0 — 2026-06-10

The all-greens release: for the first time on the CIR backend, the full
integration suite passes — **547 passed / 0 failed / 0 timed out / 26
skipped**. The last red, `testfstream`, now runs as standard C++ through real
libstdc++ headers, powered by two compiler-level advances: alias-spelled
reference returns (an alias is a *type*, not a spelling) and on-demand
namespace function-template **body** instantiation, which compiles the
non-exported libstdc++ template bodies (`__gnu_cxx::__stoa`,
`std::__detail::__to_chars_*`) that mangled-direct binding can never reach —
so real-header `std::to_string(42)` and `std::stoi(string)` execute.

## Highlights

- **Alias-spelled reference returns**: `typedef T&` / `using = T&` resolve to
  a reference-marked type (`DataDefREF`) instead of degrading to a pointer;
  `basic_string::operator[]`'s `reference` return derefs at use and `&s[1]`
  is an lvalue, exactly per the g++/clang canonical-type model.
- **Namespace function-template body instantiation** (Borland monomorphize at
  the call): deduction over bare/cv/`*`/`&` shapes, structural function-pointer
  matching (`&std::strtol`), single-element trailing parameter packs, simple
  defaulted template params, and explicit call template args
  (`__stoa<long, int>`) — instantiations join the overload-set ranking.
- **Real-header `std::to_string` / `std::stoi`** run end-to-end (the bodies
  call the instantiated internals; stoi's local `_Save_errno` RAII class with
  ctor/dtor works inside the instantiated body).
- **testfstream rewritten to standard C++** (g++- and clang++-validated)
  compiled through real system headers via `.flags`/`.expect` fixtures —
  ofstream/ifstream file I/O, chained `getline`, conversions, `system()`.
- **C++ [namespace.udir] unqualified-call fallback**: `getline(inf, line)`
  resolves to `std::getline` even when POSIX `::getline` claims the global
  name (active using-directives join unqualified call resolution).
- **Fortify builtins**: `__builtin___memcpy/memmove/mempcpy/memset_chk` and
  `__strncpy/strncat_chk` supported (glibc `_FORTIFY_SOURCE` headers).
- **Overload-ranking correctness**: parse-time-filled default arguments no
  longer poison CIR re-ranking (`user_argc`), and bare function arguments
  bind function-pointer parameters (function-to-pointer decay) in scoring.
- **General parser fixes** flushed out by the above: `current_namespace`
  restore in statement-level qualified calls, `struct X {...} const var;`
  declarators, function-local class handling across template instantiations.
- Earlier in the cycle (post-v0.26.0): `testloop`, `testdefer`, and
  `testlargesizeofquery` went green (virtual-base `__this` for external
  methods, namespace-scope type visibility, defer execution on CIR, 64-bit
  array dims), and C++ namespace free-function **overload sets** landed.
- gcc.c-torture holds at **1567/1685 (93.0%)** with a byte-identical failset
  across the entire cycle; SMAUG 1.8 boots and runs via `--project`.
