# Release v0.22.0 — 2026-05-26

Major transpiler pipeline work: the Gecko+MIR backend gains a semantic
pre-pass, managed string runtime, O(1) AST dispatch, and full iostream
wrapper support. Transpiler test matching rises from 274 to 283 out of 473.

- Phase 2 semantic pre-pass (SemaInfo, TypeClass enum)
- Phase 4 string runtime (managed std::string via extern C wrappers)
- O(1) anode dispatch via Gecko's gp_set_anode_code API (156 codes)
- Hash map tokenizer keyword lookup (replaces ~60 strcmp/token)
- Generic ostream/istream wrappers (cout, cerr, cin, any stream)
- 106 extern "C" namespace function wrappers (php, perl, python, ruby, js, rust)
- Class inheritance field copy + base-chain method resolution
- __attribute__((...)) skipping in tokenizer (unlocks 9 tests)
- typeof type specifier support
- Expression type inference for cout format selection
- New rule: enum-over-strings.md

See [CHANGELOG.md](../../CHANGELOG.md) for full details.
