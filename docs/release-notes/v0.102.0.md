# Release v0.102.0 — 2026-10-06

**Chthonia leaves madc, and the C front end tightens.** v0.102.0 is the clean
divide: everything since v0.101.0, with the Chthonia teaching IDE moved to its
own repository, where it requires and installs into madc. No madc release ever
packaged Chthonia, so nothing is lost on upgrade, and libmadcide — madcide's
base — still ships. The rest of the release is a C-conformance correctness
burn-down across declarators, declarations and initializers, the GNU/clang
vector builtins, more REPL and madcide, and one `.deb` per Ubuntu release.

## Highlights

- **Chthonia moves to its own repository.** The teaching IDE built on madcide's
  base now lives and releases separately, requiring and installing into madc;
  the madc packagers no longer build or install it, and libmadcide still ships.
- **C declaration conformance.** Redundant parentheses around a declarator-id
  (`static int ((foo))(int wat)`), implicit int after a storage class or
  qualifier (`static baz = 42;`), C's `auto` storage class (`auto int d = 4;`),
  a call through an unprototyped declaration before its definition, tagless
  aggregate declarations, and a typedef after the type specifiers all parse as
  gcc and clang accept them.
- **va_arg reads a full type name.** `va_arg(ap, int (*)(void))` and
  `va_arg(ap, char (*)[4])` read abstract declarators through the shared
  type-name reader, and member access on a `va_arg` result works.
- **The vector builtins.** `__builtin_convertvector`, `__builtin_shufflevector`
  and `__builtin_shuffle` are recognized and lowered to c2mir's shape, and a
  file-scope integer vector keeps its brace-list initializer.
- **Initializer edge cases.** Brace elision in a list mixing braced and flat
  elements, char arrays from braced or parenthesized string literals, braced
  scalar initializers in C, and a pointer to an array of unknown bound that
  emits `[]` all match the C standard.
- **__FILE_NAME__ is predefined** (gcc 12+ / clang), and `__FILE__`,
  `__FILE_NAME__` and `__LINE__` now answer defined for `#ifdef` / `defined()`,
  so the macOS prelude's `assert()` expands.
- **More REPL.** `.load` / `.type` / `.help` / `.quit` command aliases,
  `%call`, `%build`, `%open` / `%edit`, `%run` / `%load` with session payloads,
  and a Variables view driving `%whos`.
- **More madcide.** A Markdown lens, preview and span highlighting; read-only
  git views (`%git`, View ▸ Changes / History / Blame); an interactive Help
  system; Recent Files; projects and native builds with a Build menu; and
  selection, clipboard and Program-arguments refinements.
- **One .deb per Ubuntu release.** `package_release.sh` builds
  `madc_<ver>-1~ubuntu<VERSION_ID>` on that release's glibc, libstdc++ and
  headers, with Depends generated from the shipped binaries; package file modes
  and shipped-license notices are gated.
- **Forest and platform fixes.** The forest records pointers to members and
  restores a union with member functions, so std::function survives the Ubuntu
  22.04 pack; a multi-TU C++ `--project` link no longer crashes on win64; the
  forest moves into libmadc on darwin and Windows.
