# Release v0.21.1 — 2026-05-25

Const enforcement, access control, automatic token position inheritance,
and a major architecture research effort leading to the decision to adopt
MIR as madc's optimizing JIT backend.

- **Top-level `const` enforcement** — all 12 mutating operators checked, distinguishes top-level vs low-level const
- **`const T&` parameter enforcement** — compile error on mutation of const ref params
- **`public:`/`private:`/`protected:` access control** — class members and methods respect access specifiers
- **Automatic token position inheritance** — eliminates 0:0 positions in error messages, prepares for IDE features
- **JIT IR architecture research** — cross-referenced 13 JIT engines (V8, HotSpot, LuaJIT, MIR, RyuJIT, PyPy, Julia, Cranelift, TPDE, dstogov/ir, GCC, LLVM)
- **MIR backend decision** — adopt MIR (MIT, ~16K lines C) as optimizing backend replacing asmjit. 12 optimization passes, 91% of GCC -O2, 5 architectures, 66% smaller binary
- **475 integration tests, 0 failures**

See [CHANGELOG.md](../../CHANGELOG.md) for full details.
