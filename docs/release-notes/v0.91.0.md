# Release v0.91.0 — 2026-08-19

`std::setprecision` / `setw` / `setfill` work — the second and last
recorded priority residue from v0.88.0 closed.

- Parametrized manipulators are PLAIN STRUCTS consumed by free
  `operator<<` templates; both free-operator template lanes assumed
  class-hood, which those structs never earn. The char inserter template
  claimed the call (struct-as-char by value, a c2mir check error naming no
  operator); `_Setfill<char>` was refused outright by the template-id
  deduction lane.
- Struct arguments now reject arithmetic parameters exactly like class
  arguments ([conv]: no standard conversion); plain-struct parameters take
  the named-type identity lane; the template-id lane accepts plain-struct
  arguments (everything it needs lives on the base DataDef).
- Gate: `tests/testiomanip.mad`, g++ AND clang++ -O0 byte-identical —
  including a manipulator applying to a streamed `value` exactly as to the
  contained type (the v0.88.0 contract).
