# Release v0.6.0 — 2026-04-16

Massive C compatibility push toward running the SMAUG 1.8 MUD codebase. All 5 items in Phase A (pointer/type system), all 3 items in Phase B (macros), and partial Phase C (data types) are complete. madc can now parse and execute SMAUG-style C patterns including struct pointer chains, CREATE/DISPOSE macros, bitfield operations, enums, and typedefs.

## Highlights

- **Pointer declarations**: `char *`, `int *`, `void *`, `struct *`, `char **` in declarations, struct members, and function parameters
- **`->` operator**: struct pointer member access, including chained access via temp variables
- **`&` address-of**: get pointer to stack-allocated structs for function calls
- **`(TYPE *)` cast expressions**: `(CHAR_DATA *) calloc(...)` and similar patterns
- **Forward typedef struct**: `typedef struct char_data CHAR_DATA;` before struct body
- **Function-like macros**: `#define CREATE(result, type, number)` with parameter substitution, `\` continuation, and `do { } while(0)` bodies
- **Compound types**: `unsigned char`, `short int`, `long`, etc.
- **`enum`, `static`, `const`, `extern` keywords**
- **Compound assignments on struct members**: `SET_BIT(ch->act, BV00)` via `|=` on `->` members
- **Bug fixes**: ternary in parentheses, variadic arg promotion, do-while loops, C string function redirect
