# Release v0.33.0 — 2026-07-04

The parse-once release. The template re-parse deprecation campaign (Phase 5)
is complete: every member-template instantiation — first or repeat — takes its
body from tsubst over the one saved pattern tree, exactly the g++ model, and
the re-parse fallback machinery is deleted outright (a coverage gap is now a
loud compile error, never a silent re-parse). The release also fixes a
long-standing map-iteration SIGSEGV and makes the portable `--emit=c11`
output for container code compile clean under gcc.

## Highlights

- **Parse-once tsubst is unconditional and fallback-free.** Suite-wide
  burndown: 312 HIT / 0 FALLBACK (100%), zero `[why:]` reason-classes; the
  pre-acceptance eligibility census is empty across all 693 tests.
- **Seven copy-time KINDs** landed in slice 4b, ending with the SET wall
  (reference-formal object-arg address recovery) — set, map, vector,
  subscript, and container-dtor tests all lower every instantiation via
  tsubst.
- **First-skip is production:** the eager first body parse is retired from
  the hot path; instantiation is by-need (the eager parse had been
  over-instantiating redundant `allocator_traits::construct` overloads).
- **The re-parse machinery is deleted** (−123 lines):
  `materialize_tsubst_skipped_body`, the captured-span tokens, and the
  first-eager flag are gone; the parse-once rule forbids reintroducing any
  re-parse recovery path.
- **Member templates instantiated at 2+ types** get per type-shape
  instances (single-`__mti`-slot collision fixed).
- **Map iteration fixed:** `for (map<K,V>::iterator it = m.begin(); ...)`
  no longer SIGSEGVs — a class-typed for-init declarator lost its injected
  construction; the loop now lowers inside a synthetic block via the shared
  `class_decl_stmts` helper. New `tests/testmapiter.mad`.
- **Portable `--emit=c11` on container code:** tsubst dtor externs are now
  typed forward protos; emitted C for map/set/vector compiles unpatched
  under `gcc -O0` with JIT-matching output.
- **Loud-error contract:** a tsubst bail on a covered or skipped body is a
  pre-c2mir error naming the reason — regressions cannot hide as fallbacks.
- fulltest **677 / 0 / 0 / 16** with the flag-on ratchet GREEN.
