# Release v0.38.0 — 2026-07-22

The system-object release: `madc::sys` brings the Python `sys`
convention to madc — one typed object carrying the program's runtime
facts and argument lists, identical across the JIT, native artifacts,
`--emit=c11`, and script mode. The polyglot `array` gained its first
native methods (`count()`/`size()`), and the campaign's recon fixed a
cluster of general language gaps (array struct members, madc-array
subscript reads, extern-of-class emission). This is also the release
that meets the master-promotion gate.

Highlights:

- **`madc::sys` (task #91):** `sys.argv` / `sys.path` (mutable madc
  arrays) and `sys.platform` / `sys.version` / `sys.hostname`
  (immutable facts), declared by `#include <ns_madc>` — the Python
  `import sys` parallel. One population path in every lane:
  `__madc_sys_init(argc, argv)` injected at `main` entry before global
  initializers. Deliberately no `sys.argc` (the array is self-sizing);
  bare `argc`/`argv` remain the raw C door.
- **`MADC_VERSION` preprocessor macro** — the compile-time version
  string; `sys.version` is its runtime spelling.
- **Native array methods:** `a.count()` and `a.size()` on every
  receiver shape (locals, struct members, `madc::sys.argv.count()`),
  lowering to the existing `madarray_size` runtime entry through the
  same external-method path `string::length()`/`size()` use. The
  fuller method surface (`.push()`, …) lands with the
  array-as-real-class retirement.
- **Frozen values:** `madc::value::freeze()` (`MADC_VF_CONST`) enforces
  read-only values at every mutation entry point — loud error, never
  silent — as the general embedding primitive.
- **General fixes:** array struct members now lay out, construct, and
  destruct correctly; madc-array subscript reads route through runtime
  getters with string-first element typing; extern variables of class
  type emit proper struct tags; namespace-extern member access resolves
  through the Itanium storage alias; bare `cout << argv[1];` works as a
  top-level script statement.
- **Fork release pairing:** each madc release now places an annotated
  `madc-vX.Y.Z` tag on the MIR fork at the pinned commit; `MIR_COMMIT`
  stays the machine pin.
- Three new integration tests (`testsysobject`, `testsysscript`,
  `testarraymethods`) plus the campaign's recon tests
  (`testarraymember`, `testarraysubscript`, `testscriptstream`);
  fulltest and the packed suite at **740/0/0/13**, native `--exe` lane
  **726/0**. gcc-torture promote gate re-verified: 1614 ≥ 1608, zero
  class-(a) failures outstanding.
