# Release v0.83.0 — 2026-08-17

Uniform function call syntax comes to the madc dialect. Under `--std=madc`,
`x.f(y)` and `f(x, y)` are interchangeable spellings of the same call, in both
directions — and because a fallback only ever fires where the code was already a
hard error, no program that compiled before v0.83.0 can change meaning. Every
explicit `--std=c*` / `--std=c++*` mode is byte-identical to v0.82.0.

- **Both directions, two separate ordered fallbacks, never a merged overload
  set.** `x.f(y)` prefers a member and falls back to `f(x, y)`; `f(x, y)` prefers
  a declared free function and falls back to `x.f(y)` before the usual
  unresolved-symbol handling. This is Stroustrup's unified-call model (N4174 and
  the 2016 background note), which C++ itself did not adopt.
- **The receiver is passed exactly as written** — no implicit `&`, no implicit
  `*`, no type change. That makes `.` and `->` the same operator in the fallback
  leg, so C pointer APIs read naturally: `fp->fclose()` is `fclose(fp)`.
- **Every receiver kind participates:** classes, plain structs, `int`, `char *`,
  arrays, and operator-result rvalues like `(n + 1).twice()`.
- **Calls chain.** `n.twice().inc().twice()` is `twice(inc(twice(n)))`, mixing
  members and free functions in either order — with no machinery added for it,
  because both fallbacks resolve into ordinary call nodes.
- **Member-only container operations gain the free spelling:** `count(m, k)`
  resolves to `m.count(k)`. `size`, `begin`, `end` and `empty` need no help — the
  standard library already declares free versions, and those keep resolving to
  the real `std::` functions.
- **Borrowed-language namespaces read as methods** when they are already visible,
  through madc's ordinary unqualified lookup. No new lookup rule, no
  per-namespace special-casing.
- **A static member never captures a call**, access control is enforced on the
  selected overload, and when both lookups miss madc reports one error naming
  both attempts rather than a bare "no such member".
- **`madc --version` / `-V`** reports the version, with a gate asserting the CLI
  flag, the `MADC_VERSION` macro and `madc::sys.version` all agree with the
  `VERSION` file.
- **New gate: `scripts/ufcs_gate.sh`**, in `fulltest`. It sweeps the whole
  `--std=` matrix — 12 C and 9 C++ modes × 3 probes — to keep the feature inside
  the dialect, and asserts the entry condition has exactly one owner in `src/`.
