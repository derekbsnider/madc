# Release v0.68.0 — 2026-08-06

**The libc++ LANE-ZERO release.** The P2.7 stdlib-flavor parity campaign
completes: madc now runs its entire integration suite under libc++-18 with
**zero failing tests** — `run_tests.sh --stdlib=libc++` measures
**993 passed / 0 failed / 0 timed out / 13 skipped** at the release HEAD,
full behavior-parity with the default libstdc++ flavor (the 13 skips = the
9 baseline backend skips + 4 documented flavor-scoped fixtures). The lane
moved **891/28 → 0 failing** across this release with zero newly broken
tests at every comm-diffed step, and `docs/parity/libcxx-failset.txt` —
having reached the zero its charter defined — is now the lane's regression
gate. Default fulltest is **997/0/0TO/9skip**; native EXE/OBJ legs
**976/0**.

Beyond the parity campaign, the release restores **zero-ceremony madc
mode**, teaches **multi-return real types** (class values, Go-style
heterogeneous signatures), and ships a **machine-verified documentation
overhaul**.

## Highlights

- **Multi-return grows up.** Values of any copyable type travel a
  synthesized struct transport — `double` stops silently truncating,
  `const char*` stops printing pointer bits, `std::string` works with
  real copy/destructor semantics, and the Go-style declared form is
  callable at last: `(int, string) lookup()` returns an int and a real
  string. Misuse (wrong receiver count, calling in expression position,
  a bare `return;` in a multi-return function) rejects loudly with named
  diagnostics.
- **Zero-ceremony madc mode is back.** In the default dialect,
  `string s = "hi"; cout << s << endl;` and bare `php::trim(s)` are
  complete programs: well-known identifiers auto-include their real
  headers in the official order, and unqualified names walk a default
  namespace preference (`c, std, php, perl, python, ruby, js, rust,
  madc`). Standards modes stay strict; embedding-host security policies
  are honored.
- **Runtime eval documented and the docs machine-verified.** New
  `language/eval.md` (the `madc::eval_*` API: expression/unit eval,
  call-site scope capture, context objects), new `language/overview.md`
  and `language/cpp-features.md`, CLI-centered `usage.md`, namespace docs
  audited against the real exports — and a harness that runs every fenced
  example: 52/52 green.
- 🏁 **The #110 pack wall fell — libc++ `std::tuple` works.** A
  template-template parameter defaulted to a *different* named template
  binds as a template NAME ([temp.param]p11) — libc++ `tuple()`'s exact
  ctor idiom (`_IsDefault = is_default_constructible`) previously captured
  as a never-foldable non-type default, so the ctor never instantiated.
- **`noexcept` is a real operator** ([expr.unary.noexcept]): tri-state
  conjunction evaluation over the unevaluated operand with [temp.inst]/14
  on-demand instantiation — the nothrow-trait family stops silently
  folding 0.
- **`sizeof...` is a real unary operator** backed by a pack-arity scope
  stack; all three hand-matched token folds deleted.
- **C++20 abbreviated function templates** (member form): `auto`
  parameters desugar to an invented template head ([dcl.fct]/18).
- **Aggregate list-init correctness** ([dcl.init.aggr]): braced
  construction and all three declaration lanes stop dropping initializers
  on ctor-less classes — silent-garbage fixes in the default lane too.
- **Transitive secondary vtable groups** (Itanium): every polymorphic
  base subobject off the primary chain gets its own vtable group —
  stringstream/iostream inserts were silently lost through a wrong
  vbase-offset slot.
- **Overload-set and trait correctness**: using-declared functions join
  the target namespace's overload set ([namespace.udecl]); ctor templates
  no longer refuse same-class constructibility; extern linkage-block
  context stops leaking into function bodies ([dcl.link]p7).
- **Owner consolidation with gates**: forwarding-reference deduction,
  member-template parameter handling, and reference-argument lowering
  each collapsed onto one owner (six weaker duplicate copies deleted);
  three new ownership gates ride fulltest so the copies cannot regrow.
- **MIR fork raises** (fork release **1.0-madc.0.68.0**): const
  `__int128` file-scope initializers, empty-struct call-result frame
  slots, and `_Complex` return-value conversion.
- **Freeze/thaw under a flavor**: the flavor runtime participates on both
  sides of the freeze boundary — `--freeze-run` works under
  `-stdlib=libc++`.
