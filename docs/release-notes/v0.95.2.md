# Release v0.95.2 — 2026-08-23

The v0.95 line's darwin-lane conformance patch, and the tag the six
public binaries ship on. All v0.95 features are described in
[v0.95.0.md](v0.95.0.md); the win64 `--project` fix is
[v0.95.1.md](v0.95.1.md).

- **The darwin cross build (clang, `-Werror`) compiles clean**: full
  `override` coverage in the four core headers (437 members,
  compiler-enumerated) and nine `(p ? p->as_x() : NULL)` boolean sites
  rewritten to `(p && p->as_x())` — both clang-only diagnostics the
  de-RTTI sweep predated; behavior-neutral by construction.
- **darwin pack baseline 58 → 64**: six libc++ `<filesystem>`
  constructs now refuse loudly instead of silently binding the wrong
  function through the fallback v0.95.0 deleted (verified against a
  pre-branch pack rebuild); consumers fall back to live parse, and the
  ranker gap is on the burndown list.
- Process: promote.md now runs all three platform lanes BEFORE
  tagging.

See [CHANGELOG.md](../../CHANGELOG.md) for full details.
