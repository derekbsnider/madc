# Release v0.34.0 — 2026-07-11

The pack-time drain release. Phase 2 rung 1 of the embedded-header-forest
work is closed: a `--freeze`/`--freeze-append` parse now drains every
deferred header body to fixpoint and freezes the *evaluated* state, with a
pack-side c2mir check gate validating every drained lowering and
error-tolerant reverts guaranteeing a parser gap in a body nobody calls can
never poison a pack. The packed binary runs the entire integration suite —
681/681 — and beats the previous release's -O2 *live-parse* wall on the
headline test while carrying a corpus an order of magnitude larger.

Highlights:

- **Pack-time deferred-body drain (rung 1):** deferred bodies materialize
  and lower at pack time — once ever — instead of once per consumer
  compile; consumer-side body derivations on testsubscript drop 217 → 187,
  with the remaining tail tracked per-freeze in the pack log.
- **Pack-side c2mir check gate:** new fork API (`c2mir_check_tree`,
  `c2mir_copy_tree`, pinned @062dd97) checks every drained lowering at pack
  time with per-definition error attribution; defective defs drop and
  revert, never freeze.
- **Error-tolerant reverts, no silent caps:** drain failures re-insert
  their DEFBODY; cascade drops of eager-parsed source functions revert to a
  captured body-span carry (this restored packed `std::stoi`/`std::stod` —
  the packed suite's last two failures); local-class methods and
  instantiation products stay consumer-invisible and re-instantiate fresh,
  exactly like a live parse.
- **Emission split:** what `--run-frozen` compiles is decoupled from what
  consumers see, preserving whole-TU MIR byte-identity by construction;
  unresolved drained-library imports prebind to named trap stubs.
- **First fully-green fulltest of the drain era:** suite 681/0/0/16 plus
  every ratchet, the self-exe gate, the 18/18 bind gate (including
  freeze+bind == live == expected on the owner's-bar test), and both
  forest oracles.
- **Packed suite 681/681** — the packed binary compiles and runs the whole
  integration suite with zero failures for the first time.
- **Dual-binary build:** `make` → `bin/madc` (dev -O0), `make release` →
  `bin/madc-release` (-O2, stripped, forest-packed), `make debug` →
  `bin/madc-debug`; per-mode names and a lib mode-stamp end the silent
  cross-mode clobber/skew for good.
- **Timing trend tracking:** `scripts/forest_phase_bench.sh` appends
  live/bound medians, derivation counts, and load to
  `docs/perf/forest-timings.tsv` — current row: live -O0 2.593s, bound
  packed -O2 0.965s (vs 1.006s -O2 live baseline).
- **forest_index_oracle** learned the `__i<spelling>_<hash>`
  instantiation-mangle scheme (products are minted, never index lookups).
