# Release v0.20.1 — 2026-05-25

Code cleanup Phase A: compiler restructuring and tooling.  The monolithic
`compiler.cpp` (15,835 lines) has been split into 4 focused files, reducing
the core file to 8,330 lines.  A new `--emit-function` CLI tool enables safe
verbatim function extraction for future refactoring.

- compiler.cpp split into compiler_builtins.cpp, compiler_control_flow.cpp,
  compiler_operators.cpp, plus shared compiler_internal.h
- Builtin dispatch table replaces 550-line if-chain (43 entries)
- Generic walk_ast() template for AST traversal
- `--emit-function` CLI tool for extracting functions by name
- TokenCpnd::end_line tracking (IDE infrastructure)
- `--no-includes` flag for tokenizing non-madc source
- Makefile test fixes for LD_LIBRARY_PATH and libmadc.so dependency

See [CHANGELOG.md](../../CHANGELOG.md) for full details.
