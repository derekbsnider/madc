# Release v0.79.0 — 2026-08-14

The Win64 JIT milestone is closed. The hosted MinGW+UCRT build now runs
every eligible integration test without a failure, while the branch's
last divergent layout and preprocessing engines have been consolidated
behind explicit owners and negative-controlled gates. This is the JIT
milestone; PE/COFF output, Windows groves, and the public zip artifact
remain W3–W5.

- The persistent-Wine domain moves from **947 passed / 30 failed / 59
  skipped** at handoff to **987 passed / 0 failed / 0 timed out / 55
  skipped**; the 55 are 25 libc++-flavor, 19 structural Win64/POSIX, 2
  Wine-environment, and 9 known MIR exclusions.
- The LLP64 burndown fixes namespace widths, integer folding, Microsoft
  bit-field units, memory-shaped scalar boundaries, C++ base
  tail-padding reuse, Win64 setjmp/longjmp preservation, and conforming
  macro prescan/blue-paint behavior at their owning layers.
- `exec://` tests spawn the exact madc artifact under test through
  `MADC_BIN`, using a deterministic `.mad` child instead of external
  `sort`; all remaining sort-domain skips are unnecessary on their
  merits, while `std::string` channel overload coverage is restored.
- Quote-aware preprocessing groups use the one delimiter tracker, and
  macro replacement uses one expansion engine for prescan, blue paint,
  token paste, and variadics; both families have negative-controlled
  fulltest gates.
- `DataDefSTRUCT` is the one aggregate-layout owner. Versioned MC11
  aggregate/member records carry settled size, alignment, pack, byte
  offset, bit offset, and width to c2mir and emitted C, covering packed
  structs, unions, unnamed/zero-width fields, classes, and forests.
- MSVC is explicitly limited to non-ABI Windows API/UCRT semantic
  evidence; MinGW GCC owns Win64 ABI, layout, calling convention,
  mangling, and object-model questions, with Clang as the required
  second opinion.
- Final gates at code head `3d5bd90c`: Linux fulltest **1033/0/0TO/9**,
  libc++ JIT **1029/0/0TO/13**, EXE **1004/0**, OBJ **1004/0**, and
  hosted Win64 under persistent Wine **987/0/0TO/55**.
