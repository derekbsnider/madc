# Release v0.47.0 — 2026-07-25

Forest-carriers S2: **emitted-pack**. madc-emitted native executables can
now carry a frozen forest container in their self-image carrier —
`--pack-forest=<container>` with `-o`/`-shared` appends the ELF trailer on
Linux and, on Mach-O targets, rides a new fork-writer seam that lays a
`__MADC,__forest` section inside the emit-time ad-hoc code signature:
signed once at emit, no post-link surgery, no re-signer anywhere on the
product path. The full native loop (freeze → pack-emit → AMFI → read-back)
is green on Apple hardware, both architectures.

- `--pack-forest=<container>`: embeds a frozen container in emitted
  native executables/shared objects; `-c`/`-r`/JIT runs refuse it loudly,
  and a non-container payload fails the emit via the production reader.
- Fork seam (`1.0-madc.0.47.0`): `MIR_object_exec_params.extra_*` — one
  optional caller-named read-only segment/section pair laid between
  `__DATA` and `__LINKEDIT`, covered by the emit-time CodeDirectory
  (the `-sectcreate` shape, now first-class in `mir-macho.c`).
- Mach-O file-probe read-back arm: `--dump-forest` / `--forest-bind=` /
  `--run-frozen=` find a packed Mach-O file's container via a
  host-neutral load-command byte parse — the Linux cross madcs verify
  emitted darwin images, and hosted madc reads packed files on the Mac.
- `madc::dis::snapshot_append_blob`: the placement-2 append (pad-to-16 +
  blob, footer at EOF) extracted to a single owner; `--freeze-append`
  and the ELF pack arm share it.
- Hardware evidence (both arches, A64 native + X64-under-Rosetta):
  cross-emitted packed binaries carrying the real 30-unit darwin groves
  run under AMFI rc-exact; hosted `--dump-forest` over packed images is
  byte-identical to the containers; hosted madc freezes and emits packed
  natively on the Mac.
- New permanent Linux gate `scripts/forest_emitpack_gate.sh` in fulltest
  (ELF run + dump parity + refusal arms; per-arch Mach-O dump-parity
  legs).
- Build fix: per-target MIR variant-lib rules FORCE-recurse so fork
  source changes can never go silently stale under existing build dirs.
- darwin `--freeze-run` needed nothing (temp-file container + re-exec +
  file probe — no self-rewrite); the re-signer for rewriting EXISTING
  signed binaries is consciously deferred (dev convenience, not the
  product path).
