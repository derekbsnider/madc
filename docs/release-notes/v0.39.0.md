# Release v0.39.0 — 2026-07-24

The AOT hardening + ELF-completion release. madc's native lane grows from
"emits executables" to a complete, hardened ELF toolchain — position-
independent executables, multi-object linking, Full RELRO + NX, and debug
info that survives multi-object links — with MIR remaining the only
compiler, assembler, and linker (no external toolchain, ever). Ships
against MIR fork release `1.0-madc.0.39.0`.

## Highlights

- **PIE by default** — `madc -o` emits a position-independent ET_DYN
  executable (`file`: "pie executable"; ASLR-ready); `-no-pie` keeps the
  fixed-base ET_EXEC. One bias-clean `_start` stub serves both; PT_PHDR
  is emitted (glibc derives a PIE's load bias from it).
- **Multi-object linking** — `madc -o prog a.o b.o` links precompiled
  `.o` caches into a native executable (PIE/`-no-pie`/`-shared`);
  `madc a.o b.o [args]` merges in memory and runs; `-r` produces one
  combined relocatable (`ld -r` shape), including `--project -r`
  whole-program `.o`. Circular cross-object references resolve at the
  merge's final emit. Duplicate strong definitions fail loudly by name.
- **Full RELRO + NX, unconditionally** — `.mir.addrpool` (the GOT) and
  `.dynamic` lead the R+W segment under a page-padded `PT_GNU_RELRO`;
  `DT_FLAGS`/`DT_FLAGS_1` carry BIND_NOW/NOW (a statement of fact — no
  PLT or lazy binding exists); `PT_GNU_STACK` marks the stack
  non-executable. Runtime-proven: the protected page maps `r--p` live.
- **Multi-`.o` DWARF merge** — `-g` debug info merges as multi-CU output
  instead of being dropped; line info, breakpoints, and backtraces work
  across every input TU. The `.o`'s debug sections are now fully
  relocatable, which also fixes external-`ld` multi-object `-g` links
  (silently corrupt for the second CU onward before this).
- **DT_DEBUG** — executables carry the r_debug rendezvous tag; gdb's
  standard probes-based solib interface works again (the long-standing
  fallback warning is gone).
- **Suite state** — fulltest + packed arbiter 753/0/0/9; native `--exe`
  and `--obj` lanes 737/0 each; fork object + load-object lanes
  1139/2278 ×2; gdb source-level gates re-proven on PIE, RELRO, and
  merged-DWARF executables.
