# Release v0.31.0 — 2026-06-30

This release retires the legacy tag-arithmetic type encoding and lays the
first primitives of the `madc::dis` development-substrate vision. Pointer and
reference derivation now live entirely in the `DataDefPTR`/`DataDefREF`/
`DataDefCONST` object graph plus the typeid table — the parallel
`base+10000`/`base+20000` "bit trick" that could not nest and collided across
its fixed bands is gone. The front-end is also faster by default, and the
c2mir compile-warning surface is at zero suite-wide.

## Highlights

- **Tag-arithmetic encoding retired (complete).** Deleted the `dt*ptr`/`dt*ref`
  enum ranges, the `rt{None,Val,Ptr,Ref,DePtr,DeRef}` macros, the static
  `rawtype(DataType)` overload, and `setRef()`; the base accessors are now
  structural and derivation is asked via `is_pointer()`/`is_reference()`/
  `base_type`/`derived_type_id`. A dedicated burndown gate enforces it stays at 0.
- **`madc::dis` substrate primitives** (development-substrate vision, rung 1):
  `intern_table`, `arena`, and `id_table` factored into reusable primitives,
  with the string-keyed `datatype_map` re-keyed onto interned ids (O(1) lookup)
  and an id-addressable `derived_type_id` API.
- **Front-end performance:** `-O2` is the default build (~1.74× faster
  front-end), token-arena groundwork landed, and two pre-existing O(n²) parse
  pathologies were fixed (memcpy-heavy bodies: 27s → 0.6s parse).
- **c2mir compile warnings: 97 → 0** suite-wide, with a ratchet gate in
  `make fulltest` that fails on any new warning.
- **Lambda `[&]` capture** of class objects and references, plus two
  pre-existing reference / function-pointer codegen fixes.
- **Two-tree tsubst widening** — continued parse-once generic instantiation
  coverage (the g++ tsubst model) driving down the re-parse fallback.
