# Release v0.96.0 — 2026-08-28

madc now compiles and runs its own C++ embedding example: `bin/madc
examples/embed_hello.cpp` works end-to-end at g++ parity, closing the
variadic class-template frontier (mixed fixed+pack heads, class-pack
`sizeof...`, static calls through `Adapter<R, Args...>`). The wave also
hardens the libmadc embedding surface and fixes two forest-artifact
defects the full push-gate battery surfaced — one of them shipped in
every packed binary since at least v0.95.2.

## Highlights

- **`bin/madc examples/embed_hello.cpp` compiles AND RUNS** — the
  embedding examples gate in `fulltest` now covers the C++ leg beside
  the C one.
- **Name lookup keeps the TEMPLATE** ([temp.inst]): a fn-template
  instantiation product no longer clobbers `namespace_map`, which
  poisoned later dependent-pattern parses with the first shape's
  concrete callee.
- **A tid-pack's element types join the instantiation memo key** —
  `get<0>(tuple<const int&>)` and `get<0>(tuple<const string&>)` are
  distinct instantiations instead of one colliding memo slot.
- **`explicit` constructors are modeled** (`FuncDef::is_explicit`,
  [over.ics.user]) and **enum pointees keep their own conversion
  domain** in overload ranking.
- **A `const T&` parameter is an lvalue** — the enumerator-prvalue arm
  excludes storage-bearing vars, fixing a silent dangling-reference
  wrong answer (`map[k2]` updating `map[k1]`'s node).
- **Constructing a `madc::engine` no longer hijacks the host's
  iostreams** — guest capture is invocation-scoped; the libmadc smoke
  lane joins `fulltest`. Engine-registered host callbacks now reach
  `eval_expression`'s child program.
- **Forest: rebound ranked constructors stamp their `__oN` symbol** —
  the memberwise copy of a struct with a `std::vector` member no
  longer dies "too many arguments" under forest bind (pre-existing in
  every packed artifact since at least v0.95.2).
- **Forest: missing-content husks re-include by canonical path** —
  fixes headerless consumers of `<sys/stat.h>` losing `__S_IFMT` to a
  grove-order basename ambiguity.
- **Sixteen new suite tests**; full push-gate battery green: JIT
  1199/0 (9 skipped), EXE 1150/0, OBJ 1150/0, packed 1199/0,
  headerless 1172/0.
