# Release v0.21.0 — 2026-05-25

Full C++ class model: constructors, destructors, operator overloading,
references, new/delete, single inheritance, virtual functions/vtables,
and SJLJ exception handling with destructor unwinding. Also introduces
a generic extern class infrastructure that replaces ~260 lines of
per-type boilerplate with a single registration call per type.

## Highlights

- **Constructors / destructors** with LIFO ordering, constructor args, early-return cleanup
- **Operator overloading** for 10 operators via generic `try_class_operator_dispatch()`
- **References (`T&`)** with auto-deref and pass-by-reference LEA
- **`new` / `delete`** with heap allocation, vtable setup, and arrow method calls
- **Single inheritance** (`class Derived : public Base`) with method/member inheritance
- **Virtual functions** with vtable dispatch and indirect calls
- **SJLJ exceptions** (`try`/`catch`/`throw`/`throw;`) via setjmp/longjmp
- **Destructor unwinding** during exceptions — runtime cleanup stack ensures LIFO destruction
- **Generic extern class ctor/dtor** — one `register_extern_ctor_dtor()` call per libc type
- **20 new tests** — 472 total integration tests, 0 failures
