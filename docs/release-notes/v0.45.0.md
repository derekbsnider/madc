# Release v0.45.0 — 2026-07-25

madc now runs natively on macOS. This release completes Phase 1 of the
madc-on-macOS Route-1 track: full madc binaries for Apple Silicon and
Intel Macs, cross-built from Linux with clang-18 + the owner's SDK +
ld64.lld, carrying their own darwin C standard headers — G2 verified
green on Apple hardware in every lane (JIT, native Mach-O AOT emit+run,
labeled POSIX symbols, ctype inlines) on both architectures.

- **Hosted macOS madc binaries** (`make -C src hosted-arm64-macos` /
  `hosted-x86-64-macos`): full compilers — JIT and native signed
  Mach-O AOT (the v0.44.0 writer becomes the native writer through
  host detection) — ad-hoc signed, runnable on run-only Macs.
- **Darwin embedded C prelude**: hosted binaries embed the C
  standard/POSIX header set as one clang-flattened umbrella
  (`-E -dD -P` keeps every `#define` so madc's own preprocessor
  installs `EOF`, `NULL`, `stdin=__stdinp`, …) plus per-name stubs;
  generated per mode from the staged SDK at build time, never
  committed. This fixes the G2 round-1 A64 garble at its root:
  undeclared printf met Apple arm64's stack-varargs ABI.
- **Apple symbol-space correctness**: `__asm("_open")` header labels
  drop their leading underscore at the parse boundary on Apple targets
  — dlsym (JIT) and Mach-O binds (AOT) both take the C name; the
  labeled POSIX family (`open`, `fopen`, `kill`, …) works in both
  lanes on hardware.
- **Parser depth fixes shaken out by real Apple headers** (all
  target-independent): full GCC `#pragma pack` semantics with
  parse-time application via a token side channel (balanced push/pop
  regions silently lost packing before), interleaved cv-qualifiers,
  anonymous/nested/union-tag function-pointer parameters, the classic
  C spiral (`void (*signal(int, void (*)(int)))(int)`), postfix `++`
  binding under a deref of a member chain (`*s->p++ = c`), `__asm`
  labels on variable declarators, `_Float16` declarations.
- **Source port pass** (Linux behavior-identical): self-exe discovery,
  `.dylib` sonames, mach memory probes, host-keyed errno accessor and
  AOT cover spellings, `RLIMIT_AS` darwin skip; embedded headers now
  classify as system headers for reachability DCE.
- **Fork 1.0-madc.0.45.0**: object layer host-independent
  (`mir-elf-defs.h`, no `<elf.h>` dependency), manual checked 128-bit
  multiply on Apple arm64 (libSystem exports no `__muloti4`).

Tests: 756 passed / 0 failed / 9 skipped (JIT); 740/740 EXE lane.
