# Release v0.103.0 — 2026-10-09

**The TUI facelift release.** madcide's terminal UI grows into the GUI's shape
— a menu bar, a toolbar, framed panes with a line-number gutter, tab strips and
a status bar, floating dialogs, the mouse, and Dark+ colour — verified by golden
screens on POSIX and, now, genuine Windows. Alongside the facelift, the compiler
holds every name as an interned `istring` and ranks embedded headers from a
build-time table, cutting the dialect compile's work roughly in half; and
madcide opens every file named on its command line, with Help pages shown in the
editor.

## Highlights

- **The TUI facelift (S2–S9).** madcide's terminal UI now draws box-drawing
  frames with a line-number gutter and current-line highlight, tab strips and a
  docked status bar, a menu bar (F10, Alt+letter, framed dropdowns), a toolbar
  with icon glyphs and a Run dropdown, dialogs/pick-lists/prompts as floating
  windows, and full mouse support — presses, drags, the wheel, and caret
  placement by pointer. Themed in VS Code Dark+.
- **The TUI goldens run on genuine Windows.** Every `tui_golden` scenario is
  replayed on a real Windows box inside a ConPTY and compared with the same
  golden the POSIX gate uses; 31 of 31 screens match on Windows 11 build 26200.
- **The Terminal tab keeps its program's colours.** A program run in madcide's
  Terminal tab now shows its SGR colours and attributes — the 8 colours and
  their bright twins, the xterm 256-colour palette and 24-bit colour — with
  every byte keeping the pen it was written with.
- **Names held as interned `istring`.** The compiler core holds every name as an
  8-byte handle to a process-wide deduplicated spelling, so a name copy is 8
  bytes and `==` is a pointer compare; parse-cost falls about 14% across the C++
  and C workloads.
- **Embedded headers ranked by a build-time table.** Whether a system directory
  shadows an embedded header is decided when madc is built, not probed on disk
  or in the pack on every compile; the dialect parse-cost workload drops from
  143.5M to 72.4M instructions (−49.6%).
- **`var.c_str()` borrows the payload, not a ring copy.** A string-kind value's
  `c_str()` returns a borrow of the carrier's own NUL-terminated payload —
  std::string's contract — instead of copying into the per-thread ring where a
  held pointer could change under a later write.
- **Namespace names colour as `namespace`.** The highlighter colours a
  namespace-name — definitions, aliases, using-directives and every qualifier
  before `::` — as `namespace`, and a scoped enum before `::` as its type.
- **madcide opens every file named on its command line.** `madcide a.c b.c c.c`
  opens all three in the buffer ring, the first shown; an `ro` after a file
  opens it read-only. Before, a second file was refused as an "unexpected
  argument".
- **Help pages open in the editor.** A help page opens in the editor pane's Help
  tab, and a new Help Index docks in the sidebar; choosing a topic opens it in
  the editor.
- **A sanitizer build instruments the fiber runtime.** ASan fiber hooks name the
  live ucontext task stack across every context switch, so a C++ throw unwinding
  on a task no longer reports a spurious `stack-buffer-overflow`; an ASan sweep
  of 66 madcide/ui tests dropped from 5 findings to 0.
