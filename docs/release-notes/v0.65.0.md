# Release v0.65.0 — 2026-07-31

The VTT wall fell: **libc++ `istringstream` RUNS**. madc grew its
answer to Itanium construction vtables — hidden `__madc_vb<i>` ctor
parameters carrying the TRUE virtual-base addresses — and the
three-link stream construction/destruction chain on top of it (a
deferred out-of-line body shadowed by its own declaration shell, the
external D1 destroying virtual bases twice, the external C1 building a
standalone layout inside a most-derived object). The libc++ parity lane
went 803/80 → **811/77** with three tests fixed and zero broken;
`teststreambool` prints byte-identical output under both stdlib
flavors — the first working libc++ input stream.

## Highlights

- **Hidden `__madc_vb<i>` ctor params — madc's VTT equivalent (task
  #83).** Every madc-emitted ctor of a vbase-carrying class carries
  the true vbase addresses; ONE predicate (`ctor_hidden_vbase_owner`)
  keys all four signature surfaces so c2mir arity-checks any
  divergence loudly. Gate `testvttinit`.
- **Base-subobject vs complete-object ABI entry points modeled.**
  New `class_base_dtor_symbol` D2 resolver (external D1 as a base
  dtor destroyed vbases twice) adopted at all three base-dtor lanes;
  `ctor_call_assemble` demotes an external C1 on the vbase-forward
  lane to the madc C2 body (the library C1 built `basic_ios` at +16
  over `__sb_`). Gate `testistream_libcxx`.
- **Shell shadowing fixed.** An in-class decl-only member no longer
  shadows its attached out-of-line definition in the
  materialize-and-lower fixpoint (`basic_ios::init` had emitted as a
  weak EMPTY body — `__loc_` frame garbage). Ships `MADC_OOL_PROBE`.
- **Dtor synthesis gates per-symbol on library D1 availability** —
  libc++'s explicit-instantiation export split broke the class-level
  premise; libc++ streams link.
- **The native oracle.** Links 2 and 3 were exposed by clang-compiling
  the emitted C (ran clean while the JIT crashed) and diffing
  `MADC_DUMP_MIR=1` against it — the C1/D1 calls appeared verbatim.
- **Lane 803/80 → 811/77** — `teststreambool`, `testusefacet_realhdr`,
  `testvbasedyn` fixed; zero broken (set comm-diffed both ways).
- **Suite 887 → 889**; fulltest 889/0/0/9, `--exe` 873/0, `--obj`
  873/0. `/dupaudit`: `dtor_symbol_resolution` consolidated;
  `ctor_call_assembly` recorded open (task #86).
- **MIR fork unchanged** (`1.0-madc.0.63.0`) — no fork release.
