# Release v0.12.0 — 2026-04-25

SMAUG Phase F front-edge wave. Thirteen parser / lexer / compiler fixes landed while probing MadSMAUG translation units one at a time (mud_prog.c, news.c, stances.c, tables.c, act_info.c, act_obj.c, boards.c, misc.c, update.c). Each fix surfaced from a specific upstream-line failure and ships with a minimal-repro integration test. Two latent bugs filed against the typed-register IR cluster (struct member offset for fields after fixed-array members; fixed-array-of-pointers subscript element type) — both blocked on the typed-register IR replacing the asmjit Compiler reg allocator pass.

## Highlights

- **Pointer-typed `*(ptr ± N)` / `*(p = ptr + N)`** — `TokenAdd` / `TokenSub` / `TokenAssign::datadef()` overrides propagate pointer types through arithmetic and assign-as-expression. Closes the SMAUG `*(start - 1) == ' '`, `*(end = start + strlen(arg)) == ' '` idioms.
- **Single-pass macro parameter substitution** — sequential per-param sweeps cascaded when a substituted value matched a later parameter's name (`CREATE(type, NEWS_TYPE, 1)`). Now walks the body once, looking each identifier up in a single param-name → arg-value map.
- **`extern RET name(args);` typed-calls via dlsym** — explicit forward declarations now resolve through `dlsym(RTLD_DEFAULT)` at compile time, with the int32 sign-extension whitelist applied to typed calls. Any libc symbol resolvable through the default search becomes typed-callable.
- **`*++p` / `*--p` followed by a binary op** — explicit `tkInc` / `tkDec` branch in the unary-`*` parser builds the right node sequence without a recursive `parseExpression` that would eat trailing binops (`*++p == 'e'` no longer parses as `*(++p == 'e')`).
- **fn-ptr-member access doesn't mis-fire on later `(`** — `ch->fn && (something_else)` and `ch->fn && macro_call(...)` no longer get parsed as a call through `fn`. Detection scans opStack for any pending operator before invoking the fn-ptr call branch.
- **Constant-expression evaluator** — added `<<`, `>>`, `&`, `|`, `^` precedence layers so `case (1 << 14):` and `case (BV0 | BV1):` const-expressions work.
- **Char literals inside function-like macro arguments** — `'\)'`, `','`, `'"'` inside macro args no longer break the arg parser. The lexer treats `'` symmetrically with `"`.
- **`(*p).member` / `*(TYPE*)expr` / `expr[i].member` / struct-array stride** — earlier session's parser/compiler fixes already on `develop`; this release ships them as a unit.
- **`struct {...} *p, *q;`** and **`type const *p` / `int * const *xpp`** — declarator gaps in `parseDeclaration` and `TokenSTRUCT::parse`.
- **`vfADDRTAKEN` pointer + `&ptr->member`** — `TokenMember::operand` loads the pointer value from its stack slot before indexing, instead of `addOffset`-ing into the pointer's own storage.
- **Compound-assign / inc-dec error diagnostics** — 13 raw `throw "..."` sites converted to `Throw(this/left/tse) << ... << flush` so messages anchor to the operator's source location.
