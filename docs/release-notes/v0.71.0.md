# Release v0.71.0 — 2026-08-08

True random access for record storage — the first two slices of the FLR
random-access & struct-schema arc
(`docs/plans/2026-08-08-flr-random-access-struct-schema-plan.md`). The
channel framework gains a truthful seekable surface with positioned IO,
the fixed-length-record driver drops whole-file materialization for
lazy geometry-only opens and O(1) locator lookups, and a new
capability-truth gate proves every capability a driver claims — a
hollow claim is now a build failure, not a review finding.

- `SeekableDataChannel`: `size`/`seek` plus positioned `read_at`/`write_at`
  (pread/pwrite shape) that never disturb the sequential position;
  cursors and point lookups share one channel without a positional race.
- The `ChannelCapabilities.seek` flag is set truthfully per fd: regular
  files claim it, FIFOs/devices/sockets/append-mode channels refuse the
  surface cleanly. `MemoryDataChannel` implements the same contract.
- FLR `open()` reads geometry and the tombstone bitmap only — zero
  records; scans stream one positioned read per row with constant memory.
- `RecordLocator::record_index`: a locator hit is one read + one decode,
  O(1); record-aligned byte offsets accepted, misaligned/out-of-range/
  tombstoned refused loudly. Inserts hand out locators.
- Positional writes end rewrite-per-mutation: updates (including the new
  `DataSet::update_by_locator`) write exactly one record; soft
  erase/restore touch only the sidecar bitmap; position-shifting cases
  (hard erase, ordered restore, compact) stream to a temp file and
  rename atomically.
- `ChannelBackedDataDriver::open_on_channel`: record drivers open over
  any seekable channel — records-over-memory for embedding hosts, and
  the injection seam the gate's read-counting proof uses.
- The capability-truth gate (`tests/unit/test_driver_capability_truth.cpp`):
  read-counted O(1) locator proof, open-reads-nothing proof,
  streaming-does-not-drain proof, a pinned claims table for dsv/flr/vlr,
  and a `sizeof(DriverCapabilities)` ratchet so a new capability field
  cannot land without a truth leg.
- Dupaudit consolidation, gated in `fulltest`: one truthful-seekability
  probe (`madc::seekable_surface`) and one cursor→container drain owner
  (`madc::copy` + `to_container`).
