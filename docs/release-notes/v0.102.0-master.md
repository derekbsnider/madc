# madc v0.102.0

**Chthonia leaves madc, and the C front end tightens.** v0.102.0 is the clean
divide: everything since v0.101.0, with the Chthonia teaching IDE moved to its
own repository, where it requires and installs into madc. No madc release ever
packaged Chthonia, so nothing is lost on upgrade, and libmadcide — madcide's
base — still ships. The rest of the release is a broad C-conformance
correctness burn-down across declarators, declarations and initializers, the
GNU/clang vector builtins, more of the REPL and madcide, and one `.deb` built
on each supported Ubuntu release.

## Features

- **Chthonia moves to its own repository.** The teaching IDE built on madcide's
  base now lives and releases separately, requiring and installing into madc;
  the madc packagers no longer build or install it. libmadcide — the base —
  still ships with madc.

- **C declaration conformance.** A broad burn-down brings madc's C parser into
  line with what gcc and clang accept:

      static int ((foo))(int wat)    // redundant parens around the declarator-id
      static baz = 42;               // implicit int after a storage class
      auto int d = 4;                // C's auto storage class
      int foo(); foo();              // a call through an unprototyped declaration

  Tagless aggregate declarations, a typedef after the type specifiers,
  struct / union / enum definitions inside a C type name, and a block-scope
  object that hides a typedef name all parse correctly now.

- **va_arg reads a full type name.** `va_arg(ap, int (*)(void))` and
  `va_arg(ap, char (*)[4])` read abstract declarators through the shared
  type-name reader, and member access on a `va_arg` result
  (`va_arg(ap, struct S).c[0]`) works.

- **The GNU/clang vector builtins.** `__builtin_convertvector`,
  `__builtin_shufflevector` and `__builtin_shuffle` are recognized and lowered
  to c2mir's shape, and a file-scope integer vector keeps its brace-list
  initializer (`static v4si g = {5, 6};`).

- **Initializer and preprocessor edge cases.** Brace elision in a list mixing
  braced and flat elements (`int foo[2][3] = {{1, 2}, 3, 4, 5};`), char arrays
  from braced or parenthesized string literals, braced scalar initializers in
  C, and a pointer to an array of unknown bound that emits `[]` all match the C
  standard. `__FILE_NAME__` is now a predefined macro (gcc 12+ / clang), and
  `__FILE__` / `__FILE_NAME__` / `__LINE__` answer defined for `#ifdef` and
  `defined()`.

- **More REPL.** The interactive session gains `.`-prefixed command aliases
  (`.load`, `.type`, `.help`, `.quit`) and `%`-commands:

      madc> %build prog.c -o prog     // compile a file to a native executable
      madc> %call fib.c(10)           // load and call the file's function
      madc> %edit sq                  // open an editor on a definition

  `%open`, `%run` and `%load` carry session payloads from the editor, and a
  Variables view drives `%whos`.

- **More madcide.** A Markdown lens, preview and span highlighting; read-only
  git views (`%git`, View ▸ Changes / History / Blame); an interactive Help
  system that opens as a tab beside your files; Recent Files; projects and
  native builds with a Build menu; and selection, clipboard and
  Program-arguments refinements. The editor shows a tab strip of its open
  buffers, the one-entry pane is named the REPL (a Read–eval–print loop), and a
  session's Symbols view spells C++ types the way C++ writes them
  (`std::vector<int>`, not the lowered C tag).

- **One `.deb` per Ubuntu release.** `package_release.sh` builds
  `madc_<ver>-1~ubuntu<VERSION_ID>` on that release's glibc, libstdc++ and
  headers, with Depends generated from the shipped binaries.

## Fixes, internals and process

- **Stability.** Closing Chthonia's window now ends its backend process — the
  session wire is a close-on-exec socket pair, so a webview's fork + exec
  helpers stop inheriting it. The editor keeps its syntax colour past an
  unopened header or a mid-file error, editing a large file in the web window
  is fast again (a keystroke's round trip dropped from ~175 ms to 10 ms on
  Ubuntu 22.04, with the REPL pane holding its scroll-back), and closing a file
  no longer turns the editor into a second copy of the REPL.

- **Forest and platform.** The forest records pointers to members and restores
  a union with member functions, so `std::function` survives the Ubuntu 22.04
  pack; a multi-TU C++ `--project` link no longer crashes on win64; and the
  forest moves into libmadc on darwin and Windows. On macOS, a linked dylib
  records its `@rpath` install name and an LC_RPATH for its directory, so a
  path- or bare-linked library resolves from a relocatable install.

- **C/C++ correctness.** Integer-first subscripts (`2["World"]`),
  stringizing-operator escapes, null `#` directives, computed `#include`
  operands, GNU `asm` statement operands, `__sync_*` legacy atomics, the GNU
  `cleanup` attribute, and a long run of template-instantiation and
  value-category fixes each ship a reducer checked against gcc and clang.

- **Packaging and process.** The rpm's `%files` ships `libmadcide.so`; the
  macOS tarball's entries get install modes; shipped-license notices are gated;
  and the Windows-zip install gate tests adjacency binding again. A CommonMark
  conformance lane joins the fast tier.
