# Release v0.16.0 — 2026-05-18

madc's `int` now matches GCC's LP64 ABI: `sizeof(int)` = 4 bytes. This
aligns struct layouts, printf format specifiers, and dlsym'd function
arguments with standard C libraries. The GCC torture test suite pass
rate reaches 75% (1264/1685).

- `sizeof(int)` = 4 bytes, `sizeof(long)` = 8 bytes — matches GCC
- Codegen: 4-byte int stack slots, in-place IR narrow-integer canonicalization, 32-bit shift wrapping
- Float/double brace initializers now work in arrays and struct members
- Removed scanf `%d` → `%ld` format-rewriting shim (no longer needed)
- `__builtin_add/sub/mul_overflow` and `_overflow_p` predicates implemented
- Ternary operator (`?:`) in constant expressions (array dimensions, `#if`)
- C23 `[[attribute]]` consumption, unary `+`, zero-length arrays
- `stddef.h` and `assert.h` embedded headers registered
- `make -C src` now builds `lib/libmadc.so` alongside `bin/madc`
- Expression sandbox: comma-operator rejection in `eval_expression`

See [CHANGELOG.md](../../CHANGELOG.md) for full details.
