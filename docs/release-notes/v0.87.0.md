# Release v0.87.0 — 2026-08-19

The range-for loop element can be the value carrier itself: `for (value v : a)`
compiles and runs, with the element keeping its kind. The madc-array loop's
element-fill dispatch — which knew only string-class elements (via
`operator=(char*)`) and scalars — gains a third arm that copies the element
whole through the new `__php_array_get_value` fetcher.

- Through one loop variable, a string element counts its length and an integer
  element throws from `count()` and is caught inside the loop body — the kind
  survives the copy.
- Copy semantics by design: elements have no stable address, the same fact that
  keeps `value &v` refused by name (the refusal is pinned by test). Mutating
  the loop element leaves the source array intact — PHP's `foreach($a as $v)`
  model.
- `auto` over a madc array still deduces `string` (the subscript's answer);
  `for (value v : a)` is the explicit opt-in for the raw carrier.
- The remaining half of the original probe — `cout << value`, which fails
  identically with no loop anywhere — is a separate streaming/operator gap,
  sized and recorded in `docs/plans/2026-08-19-range-for-auto-deduction.md`.
- Validated: fulltest 1090/0/0TO/9skip, EXE 1050/0, OBJ 1050/0, packed 1090/0,
  headerless 1064/0/35skip, census 1099 tests / 0 warnings.
