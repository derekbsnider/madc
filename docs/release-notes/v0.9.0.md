# Release v0.9.0 — 2026-04-23

SMAUG Phase F continues: three sessions of porting work against the external
[MadSMAUG](https://github.com/derekbsnider/MadSMAUG) umbrella bootstrap surfaced
a long list of C-language gaps, each of which landed here with a minimal-repro
test. The MadSMAUG umbrella now advances past `hashstr.c`, through `requests.c`
and most of `interp.c`, and is pinned at the next front edge — undeclared
`timerisset` in `do_timecmd`. Current baseline: 141 integration tests + 25 unit
tests pass on `develop`.

## Highlights

- **`->` after a function-call / subscript / cast now evaluates the call** —
  `TokenMember::operand()` now compiles non-`ttMember` parent expressions instead
  of asking them for a register that was never populated. Fixes
  `get_slot(i)->value`, `(struct X *)calloc(...)->field`, and the chained
  dispatch patterns SMAUG's command tables produce.
- **Mem-backed arithmetic + compound assignment** — plain `+ - * / % | ^ & << >>`
  and compound `+= … >>=` now materialize through temporaries when the caller's
  destination is stack memory. Fixes `number = (number * 10) + …` and
  `hash = len % STR_HASH_SIZE` on narrow stack-backed locals.
- **Control-flow parenthesis parsing unified** — `if` / `while` / `do`/`while`
  conditions now go through a single reusable helper, which closes the
  `_Bool` single-statement `if/else` parse/branch regression and makes future
  control-flow work extensible.
- **Function-pointer typedefs + decay** — `typedef void DO_FUN(CHAR_DATA *, char *);`
  and `typedef int (*UNOP)(int);` both register a `DataDefFPTR`; bare function
  name decays to address in assignment / init-list / call-arg / ternary /
  return / comma contexts (SMAUG command-table pattern).
- **Struct interop expansion** — `struct servent` (netdb), `struct sockaddr` /
  `sockaddr_in` / `in_addr` (socket / netinet), `struct stat` + `timespec`
  (sys/stat), `struct dirent` with `d_name[256]`, fixed-size array members
  in struct bodies.
- **Address-taken stack locals** — `int n; int *p = &n; *p = …;` now spills the
  numeric local to a stable stack slot so the address survives; incoming numeric
  parameters spill on entry.
- **Assignment as an expression** — `while ((p = readdir(d)) != NULL)`,
  `if ((n = get()) > 0)`, `y = (x = 42)` now return the assigned value into the
  enclosing Gp or Mem destination.
- **Embedded header coverage expanded** — full `F_*` / `FD_CLOEXEC` /
  `O_NDELAY|ASYNC|DIRECTORY|NOFOLLOW` in `<fcntl.h>`; the full Linux x86-64
  socket/network/System-V errno set in `<errno.h>`; `<sys/file.h>` with
  `flock()` and `LOCK_*`.
- **Parser robustness** — null-guard on `->` after a dereference expression
  (no more SIGSEGV, proper diagnostic); `#include`-once semantics for single-unit
  SMAUG builds; struct-member comma declarators; chained unary `*`/`**` deref;
  typed pointer returns for dereferenced call results (`*get_msg()`,
  `errno` / `*(__errno_location())`).
- **Language surface** — typed `for` init with comma-separated declarations,
  assignment expressions inside declaration initializers, C `_Bool` alias,
  binary integer literals (`0b…`), `restrict` as a parsed no-op qualifier,
  empty-clause `for (;;)`, `register` in parameter lists.
