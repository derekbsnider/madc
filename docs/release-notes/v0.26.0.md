# Release v0.26.0 — 2026-06-09

This release advances the real-header C++ track from "parses iostream machinery"
to "real libstdc++ objects work": `std::string` construction/mutation/concat,
`cout <<` (including `unsigned long` via the real member `_ZNSolsEm`), and
`std::getline` all run end-to-end through real system headers with
mangled-direct binding — no wrappers. It also lands the `--project` multi-TU
build driver (SMAUG 1.8 boots through it), unifies call-symbol derivation onto
a single drift-gated resolver, and consumes the MIR fork's complete ≤16-byte
SIMD/`vector_size` support.

## Highlights

- **Real libstdc++ `<string>`:** `std::string s("hello")`, `s += …`, `s = …`,
  `a + b`, `.size()` compile and run through the real system header
  (C++ reference returns now treated as address returns at the external-call
  boundary, with derived-to-base adjustment).
- **Real `<iostream>` output:** `cout << unsigned long` / `s.size()` bind the
  real exported member symbol (g++ match) — inline extern-template-class
  members now bind external instead of emitting bodies that forward into
  non-exported templates.
- **`std::getline` end-to-end** via mangled-direct binding for named `std::`
  free-function templates; a real-`<fstream>` ofstream write canary also passes.
- **Call-symbol unification:** one `CirBuilder::call_emit_symbol` resolver
  (`emit_symbol ?: local_emit_name ?: var_emit_name`) replaces ~8 divergent
  inline copies; `scripts/check-call-emit-symbol.sh` (wired into fulltest)
  fails the build on any new raw read — drift can't ship again.
- **`--project` build driver (v1):** `madc --project compile_commands.json`
  compiles + links + JITs a multi-TU C project in one process; `.json` sources
  default to project mode; SMAUG 1.8 boots end-to-end through it (`-lcrypt`),
  the intended faithful bring-up path with real per-file error locations.
- **≤16-byte SIMD:** MIR fork pinned at `2ffebff` — full `vector_size` /
  `ext_vector_type` coverage (arithmetic, comparisons, shifts, shuffles,
  conversions, x86-64 ABI); all 37 GCC c-torture vector-construct tests pass;
  madc lowers `DataDefSIMD` to c2mir vector types and `--emit=c11` renders them.
- **VLAs + multi-return on CIR:** function-local (multidim) VLAs with runtime
  `sizeof`, and Go-style `return a, b` / `x, y := f()` via the `__retbuf` ABI.
- **C++ object-model cleanup merged:** the retire-std-hardcoding gate is at 0
  offending lines; library classes flow through the same generic object /
  overload / mangling machinery as user classes; auto-includes are
  `--std=madc`-only; `std::cin >>` recovered via real libstdc++ operators.
- **Quality of life:** predefined compiler macros + system include paths from
  the configured compiler, `-D` defines, `enum class E : T;`, brace
  initialization `T x{...}`, `extern "C"`/`extern "C++"` linkage specs,
  `--no-auto-load`.

Baseline at release: fulltest **543 passed / 4 failed / 0 timed out /
26 skipped** (known reds: testdefer, testfstream, testlargesizeofquery,
testloop — the open fstream/getline test rewrites); gcc.c-torture
**1566/1685 (92.9%)** vs asmjit master 1645 (97.6%); SMAUG 1.8 boots and is
playable.
