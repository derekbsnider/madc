# Release v0.55.0 — 2026-07-28

Class statics now bind to their real Itanium ABI symbols — `&std::numpunct<char>::id`
resolves to the same address `dlsym("_ZNSt7__cxx118numpunctIcE2idE")` returns,
byte-identical to g++ — and the emitter gains a single enforced owner for every
Variable's emitted name. The regression that work exposed turned into a campaign:
seven instances of one defect shape ("a rule written once, applied to half its
domain") fixed around `var_emit_name`, most found by the `/dupaudit` merge gate,
all held down by a new fulltest gate. Suites: 774 JIT / 758 EXE / 758 OBJ, zero
failures, warning ratchet at zero.

- Static data members of library classes carry `storage_alias_name` = their
  Itanium symbol; non-type template arguments encode as literals
  (`moneypunct<char,false>` → `Lb0E`) in the one mangler.
- `&Class<T>::static` resolves, records its global reference, and binds to the
  real exported object (gate: `testclassstaticitanium`).
- Globals are **constructed** under their emitted names — the four `*_realhdr`
  regressions (`<compare>`'s `strong_ordering::less`) fixed at the ctor
  receiver.
- Asm-labeled functions with bodies work end to end (`int foo(int)
  asm("renamed_foo")`) — definitions follow `var_emit_name`, calls follow
  `call_emit_symbol` (gate: `testasmlabelfn`).
- New `scripts/check-var-emit-name-bypass.sh` in fulltest: strict zero on raw
  Token-held Variable emissions plus a growth-forbidden ratchet.
- dlfcn builtins declare their real POSIX pointer types; the hybrid
  `void *dlsym(long, char *)` extern and its warnings are gone.
- One qualifier-before-`::` classifier for the three expression arms (they
  disagreed on order, alias resolution, and registry coverage); `&alias::x`
  now resolves through namespace aliases.
- `operator~` / `operator,` no longer collide into one namespace parse key
  (gate: `testnsopregister`); free operators mangle their Itanium code in
  every scope (`std::operator<<` was the invalid `_ZSt10operator<<`).
- Two hand-rolled spelling scanners that predated `spelling_delim.h` adopted
  the shared owners.
- Suite tooling: `remote_build.sh` self-logs with a per-stage rc summary and
  runs `TESTS=`-scoped subsets; eval scope capture excludes declarations with
  no definition in the TU; instantiation products are off the lookup surface.

Open and recorded with reducers: `Gap{builtin_redecl_half_adopt}`
(`getenv` under real headers), GAP B (`std::use_facet`),
`Gap{ns_unary_operator_dispatch}`.
