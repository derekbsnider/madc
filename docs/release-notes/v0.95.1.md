# Release v0.95.1 — 2026-08-23

The v0.95 binary-shipping patch: the three-platform promotion gate
caught one win64 regression before any asset shipped — exactly what
the gate exists for. All v0.95.0 features are described in
[v0.95.0.md](v0.95.0.md); this patch carries the published binaries.

- **win64: `--project` no longer crashes at the first user-function
  call.** The v0.95.0 startup lever gave the project and MIR-cache
  lanes lazy first-call code generation; MIR's win64 first-call
  redirect is broken (access violation at the first lazily generated
  call — the identical run under `-g`, the eager interface, is
  byte-correct). win64 keeps the eager interface (the pre-lever,
  v0.92.1-proven behavior); Linux/darwin keep the lazy startup lever.
  The MIR win64 lazy wrapper is the recorded follow-up.

See [CHANGELOG.md](../../CHANGELOG.md) for full details.
