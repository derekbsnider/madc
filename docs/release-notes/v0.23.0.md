# Release v0.23.0 — 2026-05-27

MIR is now the default backend and clang++ is the default compiler. Transpiler
parity pushed from 400 to 410 tests passing with zero regressions. String
literals emit as `const char *` instead of managed arrays.

- MIR (Gecko+c2mir) is the default backend; `--backend=jit` for legacy asmjit
- clang++ replaces g++ as default compiler (macOS portability)
- String literals as `const char *` with temporary std::string at call sites
- +10 transpiler test fixes (header protos, extern C wrappers, type inference)
- `MADC_EXTERN_C` macros for extern "C" wrapper generation
- c2mir built-in headers replace hand-written preamble typedefs
- _Complex type mapping to struct (WIP — runtime helpers done, operation lowering next)
- STL container `_cstr` variants for `const char *` keys
- All 65 skipped tests categorized with `.mir_skip` reasons
- char** pointer depth fix for cout type inference

See [CHANGELOG.md](../../CHANGELOG.md) for full details.
