# Release v0.66.0 — 2026-08-01

The recon-then-strike release. The libc++ behavior-parity lane went
811/77 → **859/40**: the 28-test `cout << std::string` bucket fell to
one two-commit root, then eight parallel recon agents bucketed every
remaining failure against three-way madc/g++/clang++ reducers and a
five-fix strike batch took 19 more tests out — zero broken at every
comm-diffed step. Several fixes were flavor-independent silent wrong
answers.

Highlights:

- **The 28-test bucket fell (task #88):** a pattern-recipe pop kept the
  dependent body parse's collateral definitions, and a fn-template
  instantiation now outranks ITS OWN varargs placeholder — lane 76 → 59
  in one step.
- **Two-layer SFINAE viability:** an unrelated pointer argument is not
  viable ([conv.ptr]), and a scored overload miss inside an unevaluated
  operand is a SFINAE failure — the `allocator_traits::destroy` wall
  fell.
- **[dcl.enum]p11:** `Tag::enumerator` resolves for unscoped enums;
  tagged nested enumerators carry the enum type.
- **`<=>` de-hardcoded:** the lowering discovers the
  comparison-category member + payload values from the flavor's own
  `<compare>` statics (no more `_M_value`/sentinel-2).
- **Fn-template instantiation memo keys the OVERLOAD** — the libc++
  char/char* stream SIGSEGV family.
- **Pointer-param viability ([conv.ptr]):** closes the `cout << string`
  wrong-overload identity (task #90).
- **[expr.ref]p4:** `obj.member` naming a static data member resolves
  through the shared resolver.
- **Trait-fold silent wrong answers fixed:** a pre-registration
  re-entry shell is INCOMPLETE (not dependent), and a REFERENCE type is
  never a class — `__has_trivial_destructor(T&)` was inverted vs both
  canons.
- **The release battery caught and fixed its own regression:** the new
  per-overload memo key hashed the already-renamed declarator, so
  freeze producers froze duplicate instantiation products under shifted
  names (`forest_bind_gate [vecbind]` went red). The hash now skips the
  declarator name ([over.load]).
- **Overload/deduction set:** qualified-id scope is a non-deduced
  context; a class argument cannot claim an arithmetic free-operator
  parameter; declared scope `std` mangles unversioned in both flavors;
  member-template non-type defaults fill via captured constraint runs.
- Lane ledger: `docs/parity/libcxx-failset.txt` (859/40, all 40 with
  named roots). MIR fork unchanged (`1.0-madc.0.63.0`).
