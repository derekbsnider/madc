# Release v0.28.0 — 2026-06-11

The C++20 three-way-comparison release. The entire `<=>` compliance track
(cpp-support.md P2.15) is complete: from std-floor gating through `= default`
comparison synthesis, `<=>` now works the way g++ does it — faithful
`std::strong_ordering`/`partial_ordering` category objects from the **real
`<compare>` header**, no pragmatic-int shortcut. The release also completes the
template-instantiation batch (libstdc++ free-operator *body* instantiation,
reference-operand resolution), lands the libmadc eval leftovers (one
`madc::value` type end-to-end, mangled-direct `<ns_madc>`, user-call-site scope
capture), and records the user-signed gcc.c-torture failset audit that
re-defined the develop→master promote gate.

## Highlights

- **`<=>` compliance track COMPLETE (C++20, P2.15):** the token is std-gated
  (below C++20 it lexes `<=` `>` like g++); `a <=> b` on builtin scalars lowers
  to the inline byte-select category temp (g++ -O0 canon); class operands
  dispatch member/friend `operator<=>` overloads.
- **Rewritten candidates ([over.match.oper]):** `x != y` → `!(x == y)`,
  reversed `==`, and the relationals via `(x <=> y) @ 0` — a class defining
  only `operator<=>` + `operator==` gets all six comparisons.
- **`= default` comparison synthesis ([class.compare.default]):** defaulted
  `==`/`<=>` compile from the ordered member list at class completion; a lone
  defaulted member `operator<=>` yields all six comparisons (implicit
  defaulted `==`).
- **Hidden-friend machinery:** friend operator definitions hoist to namespace
  scope and compile (`r < 0` on `std::strong_ordering` calls the TU-local
  friend); literal `0` ranks as a null-pointer constant; free-operator
  dispatch is a general mechanism.
- **Standalone `#include <compare>` works** under `--std=c++20` — madc follows
  g++'s `__cpp_concepts` activation chain; `__cplusplus` now tracks the
  selected `--std=`.
- **Template-instantiation batch complete:** `a + "literal"` instantiates the
  real libstdc++ `operator+` body (Borland monomorphize); the char_traits
  explicit-specialization key fix (`length("abc")` no longer folds to 0); loud
  no-ctor-match errors with the new generic `.expect_err` test convention;
  reference operands resolve as the referenced class (`cout << s` with a
  `const string&` parameter).
- **libmadc eval leftovers:** MadValue/MadArray are deleted — one
  public `madc::value` end-to-end; `<ns_madc>` is declaration-only
  mangled-direct; runtime-eval scope capture fires at the user call site
  (int/real/array/string locals); expression-DSL string compares are value
  compares; in-process eval runs on `CirJitSession` (CIR→c2mir→MIR).
- **Promote gate re-defined (user-signed failset audit):** the 88-test torture
  failset is fully classified — 41 class-(a) standard-C bugs (the gate:
  ≥1608/1652), 14 class-(b) GNU-extension roadmap items, 33 class-(c) formally
  skipped; "match asmjit 1645" is retired.
- **Itanium mangler fix:** substitution back-ref as a name prefix keeps the
  `N..E` wrap (g++-verified), unblocking the mangled-direct `_ctx` surface.
- **Test baseline:** fulltest **572 / 0 / 0 / 18** (exit 0, both check gates
  GREEN), gcc.c-torture **1567 of 1652 in-scope (95.0%)**, SMAUG 1.8 boots
  end-to-end via `--project`.
