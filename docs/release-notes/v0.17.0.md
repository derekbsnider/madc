# Release v0.17.0 — 2026-05-19

GCC torture test parity push from 1305 to 1316/1685 (78.1%). This release
focuses on codegen correctness for integer cast chains, struct initialization,
and register-width consistency across the constant-folding and comparison
paths.

- Local variable zero-init emitted at function prologue instead of first-use
- Empty struct/union brace-init (`struct X x = {}`) uses direct zero-fill
- Constant-fold `optimize()` uses type-width registers (fixes `~0U` comparisons)
- `#pragma push_macro` / `pop_macro` preprocessor support
- `f().member` dot-access on struct-returning function calls
- `list` removed from keyword map to stop shadowing C identifiers
- Nested cast chains `(long long)(int)x` properly truncate then widen
- 274/0 integration tests, 261 unit tests, 1316/1685 GCC torture suite

See [CHANGELOG.md](../../CHANGELOG.md) for full details.
