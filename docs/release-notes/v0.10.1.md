# Release v0.10.1 — 2026-04-24

Patch release closing out the typed-register IR cleanup work that
followed `v0.10.0`.

## Highlights

- **Multi-return return-buffer normalization.** `TokenRETURN::compile`
  now routes numeric/pointer `__retbuf` slot writes through
  `IRBuilder::store` instead of open-coded Reg/Xmm/Imm/Mem dispatch.

- **Stream I/O shape normalization.** `TokenBSL` / `TokenBSR` now route
  stream string/cstr/numeric argument materialization and istream
  integer/real writeback through the shared helper / IR surface instead
  of bespoke operand-shape branches.

- **Direct-call cleanup.** The normal direct-call path no longer
  pre-allocates `operand(pgm)` before `bind_call_return`; fallback
  return storage is allocated only at the bind point when needed.

- **Final compiler-site cleanup.** The remaining obvious compiler-side
  Mem load/store sites now use `IRBuilder::store` / `load` / `coerce`
  where appropriate, including stack-local init, stack-parameter
  home-slot stores, compound/member writeback, subscript Gp stores,
  call returns to Mem, cast-to-Mem, ternary merge-to-Mem, compound
  real-member loads, and switch-expression Mem-to-int64 normalization.

- **Dead typesafe surface pruned.** Removed dead mixed Gp/Xmm
  arithmetic/compare overloads, dead Xmm+Imm arithmetic, and the dead
  `safemov(Xmm, Imm)` path.

## Test baseline

- 25 datadef + 23 IR = 48 unit doctest cases, all passing.
- 170 integration tests, all passing.

## Outcome

The remaining `safemov` uses in `compiler.cpp` are now adapter
internals, pure register shuffles, or legitimate leaf/boundary loads
rather than unfinished IR migration work. The IR cleanup track is
considered complete enough to resume SMAUG-facing compiler work.
