# Release v0.67.0 — 2026-08-01

The flavor-ABI release. The libc++ behavior-parity lane went 859/40 →
**880 passed / 26 failed / 2 timed out** — 21 net flips with zero
regressions at every comm-diffed step — and the biggest remaining dam
fell: a libc++ script can now pass `std::string` into the host's
libstdc++-built namespace functions (php::, perl::, madc:: eval)
through compiler-generated marshalling thunks. Two silent wrong-answer
classes died along the way, and `cin >> string` works under libc++.

## Highlights

- **Flavor-ABI marshalling (task #69):** a generated thunk per
  boundary callee converts script-flavor strings to host-flavor temps
  (exported `C1` ctor from `c_str()`/`size()`), copies back via the
  script flavor's `assign`, and maps reference returns through an
  alias table. Boundary detection uses dladdr module-origin equality —
  a symbol implemented by libc++ itself never marshals. Ten tests out
  in one flip; `MADC_FLVMAR=0` escape hatch.
- **Silent corruption closed:** extern-C twins taking `std::string*`
  had been fed raw libc++ string bytes — `lang`/`rust`-style tests
  exited 0 with wrong values. Marshalled now.
- **Typed protos for declaration-only Itanium callees (task #92):**
  the `<new>` `_Znwm` family no longer falls to c2mir's implicit-int
  declaration.
- **Deduction guides declare no name (task #98,
  [temp.deduct.guide]):** the phantom `array`/`vector`/`pair` VALUE
  that shadowed types in prototype parameter lists is gone.
- **#93 typedef template-arg identity landed ([temp.type]):**
  `cin >> string` under libc++; the defless-drop fix turned the forest
  self-exe gate green with it.
- **Const-overload selection is honest ([over.match.funcs]/4):** the
  implicit object parameter joins member overload selection — was
  silently wrong in both flavors.
- **Two [dcl.ambig.res] declaration readings + access control judges
  the SELECTED overload** (session #44 batch).
- Suite 902 → 911 integration tests (nine new gates). MIR fork
  unchanged (1.0-madc.0.63.0).
