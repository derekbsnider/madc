# madc v0.101.0

**madc has a REPL, and its editor becomes a teaching IDE.** Run `madc` with
no program file and you are in an interactive C/C++ session that behaves the
way Julia and IPython do: what you define in one entry is there in the next,
results are named so you can reuse them, and the session can tell you what you
have built. On top of it, madcide gains a plugin system, and the first product
built with that system is **Chthonia**, a teaching IDE modelled on Thonny. This
release also carries a long correctness burn-down that fixed silent wrong
answers first, a Linux Homebrew bottle, and an archive of every released
binary.

## Features

- **An interactive C/C++ session.** `madc` alone opens it; `madc -i prog.c`
  runs a file and then keeps its names, as `python -i` does.

      $ madc
      madc 0.101.0. Ctrl-D exits.
      madc> int sq(int x) { return x * x; }
      madc> sq(7)
      49
      madc> ans + 1
      50

  Each entry's definitions persist; statements run; an entry the compiler or
  linker refuses is rejected without ending the session, and a crash inside an
  entry no longer ends madc. Results are kept and named the way IPython names
  them (`ans`, `_`, `__`, `_N`); an array or struct result is the object
  itself. On a terminal each entry is edited with readline's keys, with a
  history file, Up-arrow prefix recall, Ctrl-R, and Tab completion of names,
  members after `.` / `->`, and scopes after `::`.

- **Ask the session.** `%whos` lists what you have defined, `%type EXPR`
  gives an expression's type without running it, `?name` (or `%pinfo name`)
  describes a name and every overload with its location, and `%help` lists
  the commands.

- **Sessions in their own process.** A session can run in a separate process
  and be driven from madc code (`madc::session_*`) or from the editor. Load
  and run replies carry diagnostic rows, a session can switch language
  standard, and Stop interrupts a running entry.

- **Chthonia, a teaching IDE.** Chthonia is madcide with its teaching
  profile: a REPL pane, a Variables view of the session's names, F5 to run
  the buffer with its diagnostics in the Problems pane, Run ▸ Language… to
  pick the standard, and Thonny's keys by default. The name mixes the two
  programs it learns from, Thonny for the IDE and Julia for the REPL, behind a
  C for C/C++ and an h for helper. Say it "THO-nee-ah".

- **madcide plugins.** A plugin is a library, source compiled in-process, or
  code in a forked child; it contributes commands, views, event handlers and
  toolbar rows through one API table. `madcide --build-plugin` builds one,
  `madc -shared` emits a Windows DLL so plugins load there too, and the
  program's name selects its profile bundle.

- **Editing.** Selection and the platform clipboard; six key styles (JOE,
  Vim, Emacs with its region, kill ring and Meta keys, Pico, Thonny, VS Code)
  under Tools ▸ Key bindings…, with modifiers on every key, saved per user;
  columns measured in UTF-8 characters.

- **Homebrew on Linux.** The release ships an `x86_64_linux` bottle and its
  formula. The macOS bottle follows in a later release.

## Fixes

The burn-down took silent wrong answers first; each fix ships a reducer
checked against gcc and clang.

- **Value categories.** An rvalue reference is its own type and a call
  returning one is an xvalue (B117, B118); an argument's value category
  decides reference binding (B92); a prefix `++`/`--` or an assignment is an
  lvalue in C++ (B116); a function template call's type is its declared
  return, reference included (B120).
- **Overloads and templates.** Out-of-line member definitions bind to the
  declaration they spell, so a `const_reference` / `value_type&&` pair (the
  `push_back` shape) no longer runs the moving body for an lvalue; every
  deducing function template is a candidate and the best is instantiated
  (B113); specializations are candidates only for their own call (B112);
  `std::make_tuple` compiles (B122); default template argument failure is
  SFINAE (B96).
- **Types and layout.** A typedef keeps its own `volatile`, so
  `std::add_volatile<int>::type` is `volatile int`; bit-field layout under the
  Microsoft rules; a local initializer zero-fills the member after a bit-field
  (B83); a later designated initializer overrides an earlier one (B138).
- **Members.** Pointer-to-member deduction and declarators (B127, B141);
  `sizeof`/`decltype` of a qualified member name (B78).
- **Output.** `format` / `print` evaluate every argument once, in order
  (B99), and print `signed char` / `unsigned char` as integers (B93).
- **Multi-TU programs.** A template instance is named from its
  specialization's identity, so two translation units give one
  specialization one symbol.
- **Found by the macOS lanes before this release shipped.** `%whos` and
  Chthonia's Variables view were empty on macOS (the session's name rule
  kept a reference to a temporary); `1 + v` and `"x" + v` on a `var`
  crashed on Apple Silicon (their runtime entries were called without a
  prototype, so the result address missed the arm64 result register); and
  Stop on an entry that never ends now restarts the session at once instead
  of after a 2-second grace.

## Infrastructure

- **Every release binary is kept.** `scripts/release_bins.sh` archives each
  released `madc-release` since v0.72.0 with its library, and `run <test>`
  shows a test's pass/fail history across releases; the master push refuses a
  release missing from the archive.
- **One seam battery.** Tier 3 is `scripts/seam_battery.sh`: the full suite
  once on the shipped -O2 packed binary with no headers on disk, then the
  smaller on-disk, Windows, native-artifact and cross-build stages, cheapest
  first.
- `make -C src release` links in a fresh clone (the thin CLI links its own
  mode's library).
- Ratchets: g++.dg C++11 now 1501 of 1946 (77.1%), gcc c-torture 1612 →
  1613, the c2mir corpora 302 of 359 → 314 of 364.
- The release assets were built from `fix/win-package-plugins-claude`: the
  `v0.101.0` tree plus one packaging-script fix (the Windows zip's plugins
  are built by the staged `madcide.exe`, beside `libmadc-0.dll`). The madc
  sources are identical to the tag. The seam battery now runs the Windows
  packager (`package-win`), so its first run is no longer the release build.

## Known open

- **B156 (silent):** `std::is_same<std::size_t, unsigned long>` is false under
  libstdc++ — the trait compares type names, and a namespace-scope typedef
  keeps its own name. Shipped in v0.100.1 too.
- **B157 (silent, libc++ only):** `std::vector::push_back(std::move(x))`
  copies instead of moving.
- libc++ gaps, each with a `.libcxx_skip` naming it: an implicitly deleted
  `unique_ptr` copy (B158, B161), multi-element `std::tuple` construction
  (B159), `std::vector`'s iterator-pair constructor (B160).
- A namespace-qualified variable template inside a function body (B154), and
  a requires-expression in a variable template's initializer at run time
  (B155), are refused.
- The packed binary SIGSEGVs on a `--project` with `<string>` in two
  translation units under forest bind (B153; `--no-forest-bind` works).
- The macOS Homebrew bottle is held for a later release.
