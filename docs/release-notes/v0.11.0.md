# Release v0.11.0 — 2026-04-24

SMAUG Phase F front-edge resumption. Twelve language gaps surfaced during whole-program porting of the MadSMAUG umbrella were closed this cycle, and the SMAUG 1.8 umbrella bootstrap now **compiles and runs end-to-end** against a stub `main()`. Every ingested translation unit compiles cleanly and every symbol resolves through the bootstrap shim; remaining work is filling out `main()` and ingesting the rest of the upstream `.c` files.

## Highlights

- **`goto label;` + forward labels** — function-scoped labels through `Program::label_map` (cleared per function); forward references resolve via look-or-create on the `asmjit::Label`. Unlocks (future) ingest of `mud_prog.c`, `magic.c`, `tables.c`, `build.c`, `mud_comm.c`, `ban.c`, `services.c`.
- **Struct-copy initialization and assignment** — `struct S a = other;` and `a = other;` lower to a single `memcpy(&dest, &src, sizeof(S))`.
- **`*p++ = rhs` as a write target** — `TokenDerefStep` LHS branch in `TokenAssign::compile` captures the pre-step pointer and exposes `[old_ptr]` as the numeric-assign Mem lvalue.
- **`(*p).member` parses as `p->member`** — dot handler now recognizes `TokenDeref` and `TokenDerefExpr` LHS forms (previously segfaulted from an unconditional `TokenMember *` cast).
- **`expr[i].member` for struct-element subscripts** — `TokenSubscriptExpr` branch in the dot handler; `TokenSubscriptExpr::compile` returns the raw element Mem for struct/class types so the dot-chain path can add the member offset.
- **Compound-assign on expression-base subscripts** — `resolveCompoundLHS` gained a `TokenSubscriptExpr` path mirroring the `TokenAssign` write branch (LEA/MOV discrimination, `imul` fallback for non-power-of-2 element sizes). SMAUG's `xREMOVE_BIT`/`xSET_BIT` macros now compile; this closed the deepest MadSMAUG compile front edge.
- **Struct-array subscript element stride + base addressing** — non-power-of-2 element sizes fold via `imul`; both subscript write and read now use `base_expr->operand()` so numeric-typed `TokenMember` bases (`struct { int bits[N]; }`) don't trigger `emit_ir_value`'s load-first-element path.
- **`class` as a plain C identifier** — SMAUG uses `class` as struct members, locals, parameters, and subscript indices. `parseStatement` routes `class` through `parseExpression` when it's not a real class-declaration head; `parsePostfixChain` accepts it after `.` / `->`.
- **`#include` canonicalization via realpath** — the include-once check keys on `realpath()` of the resolved path, so symlinked equivalents (`upstream_src/mud.h` vs bare `mud.h`) register as the same include.
- **`return X;` mis-detected as multi-return** — `TokenRETURN::parse` now consults the consumed stop token (new `Program::curToken()`) and requires `,` specifically; previously an identifier after `;` could trip multi-return and silently corrupt codegen.
- **Safemov double → Mem no longer truncates** — constant-folded `double d = 1.0 + 0.5;` now stores `1.5`, via a new Xmm-through-constpool path when the destination is a Mem and the source is real-valued.
- **Leading-dot float literal `.4`** — lexer peeks for a digit after a single `.` and parses the fractional expansion (with optional `f/F/l/L` suffix) before falling back to `TokenDot`.
- **`char[N] = "..."` with matching length skips null terminator** — C89 allows `char c[3] = "abc";`. Inferred-size and oversized cases still append `'\0'`.
- **Unary `-` in brace-init lists** — `isPostfixPosition` now rejects `{` / `(` / `,` / `;` / `=` so `int arr[] = { -5, -4 };` keeps the `-` unary. SMAUG's `const.c` lookup tables (`str_app`, `int_app`, `dex_app`, …) compile.
- **Better error diagnostics** — `resolveCompoundLHS` and `TokenStmt::compile` default-branch no longer dangle `c_str()` pointers into stderr; SMAUG-level errors now carry their real text.
- **SMAUG progress tracking** — new `docs/smaug-progress.md` records running parse / compile / link / runtime % against the upstream 158,537-line SMAUG 1.8 source.
