# Release v0.95.0 — 2026-08-23

The `ui::` data-hub surface lands with its proof: Colossal Cave
Adventure as a pure madc multi-file project, byte-identical to the
original C game across all 94 reference logs — plus the cold-startup
arc that took the packed 11-TU launch from 829 ms to the ~150 ms
class, and the zero-include dialect contract.

- **The `ui::` namespace (Track 7 Phase 1)**: world sessions over the
  tagged world format, entity bags behind one hub write path,
  projections as the access decision (`render_look`/`render_inspect`),
  a verb registry (`ui::act`), and `ui::prompt` — the one prompt
  handler (write, flush, read; piped transcripts read exactly like
  interactive sessions). Documented in `docs/language/ns-ui.md`.
- **Colossal Cave Adventure, fully playable**: 11 translation units
  compiled and MIR-linked via `madc examples/adventure/advent.cc.json`;
  one `class Game` global as the only extern; 4447 lines against the
  reference's 4681; 3 fragments + 94 whole logs byte-identical, gated
  in fulltest.
- **The zero-include contract**: a madc-dialect program needs no
  `#include`, no `using`, no `std::` — auto-include serves quoted user
  modules, `madc::getline`, `println(stderr, ...)`, and the `ui::`
  surface; brace-list value literals (`var ds = { a, b, c };`) and the
  chainable `.push()` ride the same registered rows.
- **Every polyglot public has a lean primary**: the 57 functions that
  existed only in `std::string` shape gained `value`/`char*` primaries
  with source-language parity semantics; the dialect prelude no longer
  pulls the `<string>` closure.
- **Cold JIT startup (the tinycc-parity arc)**: packed adventure
  829 → ~150 ms class via positional auto-include filtering (776K → 62.5K
  tokens), lazy first-call codegen (link 58 → 11 ms), one compile
  substrate and shared prelude images across sibling TUs, lazy
  MEMBER-template hydration (the 6.4 MB template payload never decodes
  on a C-shaped launch), the de-RTTI dispatch sweep (−14.2% Ir), a
  demand-driven derived-function restore, and page-arena c2mir registry
  storage.
- **Silent cross-TU defects fixed** (each with a pinned reducer):
  `--project` ran only one TU's global initializers; `extern var`
  declared a private copy per TU; file-scope NSDMI never applied;
  a call with no viable overload silently bound the wrong function
  (now a loud refusal); `arr[i] = x` wrote a hidden temp (every
  carrier subscript is a value lvalue over the element slot).
- **`--no-embedded-headers` now reaches `--project` translation
  units**, and the whole CLI policy-fanout family is gated in fulltest
  (`check-policy-fanout.sh`, negative-controlled).
- **Merge-wave hygiene**: scoped duplication audit consolidated the
  MEMBER param-table decoder, put the flush's eager decode on the
  forest clock, converted the last zero-filling forest decode
  destinations, and recorded the remaining families in the knowledge
  graph.
