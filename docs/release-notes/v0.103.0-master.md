# madc v0.103.0

**The TUI facelift release.** Everything since v0.102.1: madcide's terminal UI
grows into the GUI's shape — a menu bar, a toolbar, framed panes with a gutter,
tab strips and a status bar, floating dialogs, the mouse, and Dark+ colour —
verified by golden screens on POSIX and genuine Windows. Under the hood the
compiler holds every name as an interned handle and ranks embedded headers from
a build-time table, roughly halving the dialect compile's work, and madcide
opens every file named on its command line with Help shown in the editor. No
language surface changed.

## Features

- **The TUI facelift.** madcide's terminal UI now looks and works like its GUI.
  It draws box-drawing frames with a line-number gutter and current-line
  highlight, tab strips over the editor's open files and a status bar docked at
  the bottom, a menu bar reached by F10 / Alt+letter / the mouse with framed
  dropdowns, a toolbar whose buttons show icon glyphs (`▶ Run ▾  ■ Stop`) with a
  Run dropdown, and dialogs, pick lists and prompts as centred floating windows:

      madcide --tui program.c      # the full IDE in the terminal — menus,
                                   # toolbar, tabs, dialogs, and the mouse

  Full mouse support — presses, drags held with a button, the wheel, and caret
  placement by pointer — acts on whatever the grid last painted under the
  pointer, so an overlay wins. The chrome is themed in VS Code Dark+, and when
  the terminal's locale is not UTF-8 every box glyph spells in ASCII.

- **The Terminal tab keeps its program's colours.** A program run in madcide's
  Terminal tab now shows its colours and attributes — bold, dim, italic,
  underline, blink and inverse; the 8 colours and their bright twins; the xterm
  256-colour palette and 24-bit colour — with every byte keeping the pen it was
  written with.

- **madcide opens every file named on its command line.** `madcide a.c b.c c.c`
  opens all three in the editor's buffer ring, the first one shown; an `ro`
  after a file opens that file read-only, and a file named twice stays one
  buffer. Before, a second file was refused as an "unexpected argument". The
  single-file faces (`-c`, `--mcp`, `--lsp`, `--serve`) still refuse a second
  file.

- **Help pages open in the editor.** A help page opens in the editor pane's Help
  tab, and a new Help Index docks in the sidebar; choosing a topic row opens it
  in the editor. Help Contents opens the contents page and shows the index, and
  Help ▸ Help Index toggles it.

- **Namespace names get their own colour.** The highlighter colours a
  namespace-name — a namespace or alias definition, an alias target, a
  using-directive, and every qualifier before `::` — as `namespace`, and a
  scoped enum before `::` as its type rather than a namespace.

## Fixes, internals and process

- **Faster compiles from interned names.** The compiler core holds every name as
  `madc::dis::istring`, an 8-byte handle to a process-wide deduplicated
  spelling, so a name copy is 8 bytes and `==` is a pointer compare; parse-cost
  falls about 13–14% across the C++ and C workloads. A system header's
  include-guard is now decided in the one lex that reads it, not on a second
  full-text read.

- **Embedded headers ranked by a build-time table.** Whether a system directory
  shadows an embedded header is decided when madc is built, not probed on disk
  or in the pack on every compile; the dialect parse-cost workload drops from
  143.5M to 72.4M instructions (−49.6%). The build-time shadow table also covers
  the generated darwin prelude and Windows header fallbacks, fixing the darwin
  forest pack.

- **`var.c_str()` is a real borrow.** A string-kind value's `c_str()` returns a
  borrow of the carrier's own payload — std::string's contract — instead of
  copying into the 8-slot per-thread ring, where a held pointer silently changed
  under a later write; an ASan sweep of 66 madcide/ui tests shows no remaining
  heap-use-after-free.

- **Sanitizer builds instrument the fiber runtime.** ASan fiber hooks name the
  live ucontext task stack across every context switch, so a C++ throw unwinding
  on a task no longer reports a spurious `stack-buffer-overflow`; the madcide/ui
  ASan sweep dropped from 5 findings to 0.

- **REPL line editor.** Meta-b / Meta-f / Meta-d fire again when a terminal
  sends Alt+b / Alt+f / Alt+d as one burst, so backward-word, forward-word and
  kill-word work.

- **Owner gates and lane tooling.** Three owner gates recognise the definitions
  they guard again after the names-as-`istring` change moved return types off
  `std::string`. A change confined to the application set (`tools/`, the madcide
  tests, the TUI goldens and their driver) now stales only the application lanes
  (`gui`, `tests-jit`) instead of every lane.
