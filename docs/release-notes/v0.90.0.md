# Release v0.90.0 — 2026-08-19

`value(N)` constructs — the highest-priority residue from v0.88.0 closed,
and the layer chain under it fixed the whole way down.

- `value(-7)` temporaries and `value v(7);` direct-init declarations
  construct through real registered ctor overloads
  (default/cstr/int64/double/bool/carrier-copy) bound to placement-new
  `madarray_construct_*` runtime entries. Before: the carrier had NO ctors,
  the ObjTemp arm emitted nothing, and the temp's kind byte was stack
  garbage — an "instance" notice then SIGSEGV, near-silent; the parens
  declaration did not parse at all.
- One layer down, external-ctor extern prototypes flat-typed every scalar
  parameter `long long`: `value(3.5)` marshalled its double through a GPR
  the callee never read and constructed `real(0)` — a silent wrong value.
  Prototypes now derive from `native_param_shape`, the one shape owner.
- Loop-header temporaries are per-iteration: for/while/do headers that
  materialize a class temp now wrap it in a statement expression scoped to
  the evaluation — previously the temp was built ONCE outside the loop
  (stale each iteration; for a class-shape for-init, before the loop
  variable existed).
- c2mir (fork, upstream-worthy): a statement expression's value is its last
  statement AS WRITTEN — the check/gen arms no longer read the tail after
  the scope's cleanup calls were appended. MIR c-tests 1143/2286/0, exact
  baseline; a cleanup-carrying stmt-expr while-condition through c2m's own
  parser now matches gcc byte for byte.
- `for (string s("ab"); ...)` parses: a `parsing_for_init` context channel
  lets the for-init tail keep its `;` (statement contexts unchanged).
- Recorded with reducers: madc's front end ignores user
  `__attribute__((cleanup))` on locals; declaration-flow `;` conventions
  remain asymmetric (follow-up).

Gates: `tests/testvaluector.mad`, `tests/testforinitctor.mad` (g++ AND
clang++ oracle, byte-identical).

Validation: fulltest 1095/0 (0 timeouts, 9 skips), census 1104 tests / zero
warnings, EXE 1055/0, OBJ 1055/0, MIR c-tests 1143/2286/0, release +
packed + headerless lanes green, `--version` gate 0.90.0.
