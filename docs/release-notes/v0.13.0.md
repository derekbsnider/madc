# Release v0.13.0 — 2026-04-30

**SMAUG 1.8 plays end-to-end on madc.** The 158k-line C89 codebase JIT-compiles in-process and runs as a real network MUD: telnet greeting, full character creation, MOTD, room entry, and in-game commands (`look`, `inventory`, movement, `say`, `who`, `quit`) all work, including the returning-player `Reconnecting.` flow.

Four codegen / lexer fixes this session collapsed a cascade of SMAUG runtime symptoms into one root cause each. The "second-connection comm.c:1381 NULL deref", the `slot_lookup` umbrella-only int-widening bug, the spurious `Preloading player data … (-15803487K)` logs, and the chained-EOF-loop hangs were all separate manifestations.

## Highlights

- **Lexer: `\NNN` octal and `\xHH` hex escape sequences.** SMAUG's `\033` ANSI prefix was being parsed as `\0`+`"33"`, silently truncating the format string. `make_color_sequence()`'s `sprintf` returned 0 and `buf[ln-1] = 'm'` wrote OOB into `nanny()`'s descriptor pointer.
- **`scanf` family rewrites `%d` → `%ld`** (new `__madc_sscanf` / `_fscanf` / `_scanf` helpers). madc's `int` is 64-bit, but libc's `%d` only writes 4 bytes — leaving the high half stale. Fixed the underlying SMAUG `slot_lookup` "high 32 bits zero, not sign-extended" mystery.
- **`stat`/`fstat`/`lstat` join the dlsym int-returner whitelist** so the 32-bit -1 return gets `movsxd`-sign-extended into the 64-bit RAX madc reads.
- **`safemov` narrow→64 uses `movsx r64, r/m8`** instead of `movsx r32, r/m8` (which zero-extends to 64 after the 32-bit sign-extend). Fixes the chained EOF idiom for `TokenVar` LHS.
- **All MadSMAUG bootstrap shims removed.** `slot_lookup`, `act`, `to_channel`, `boot_log` now run upstream definitions. The `_bootstrap_comm_shim.c` is just a doc comment.
- **MadSMAUG `fgetc`-loop patch** for the six upstream sites that use the chained-subscript-assignment EOF idiom — worked around with an `int` intermediate until the matching codegen fix lands for `TokenSubscript` LHS.
- **238 integration + 48 unit tests pass.** Four new regressions: `testoctalescape`, `testsscanfwide`, `teststatret`, `testsignextend`.
