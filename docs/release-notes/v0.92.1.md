# Release v0.92.1 — 2026-08-20

The v0.92 line's binary-shipping patch. The new three-platform promotion
gate (every master promotion builds and validates Linux, Windows, and
macOS packages, and the platform suites gate the release) caught two real
Windows regressions in tests newer than the last win64 validation; both
are fixed here, and this is the release the six platform assets attach to.

- **win64: headerless `hypotf` (and the rest of the hidden float-math
  surface) resolves** — ucrtbase.dll does not export `fabsf` / `frexpf` /
  `hypotf` / `ldexpf` (ucrt serves them as header inlines or the
  `_hypotf` oldname; mingw-gcc statically binds libmingwex's), so the
  headerless existence probe died at parse. The complete C99 `<math.h>`
  float-suffix surface was audited against the real export list and
  exactly those four names pinned in the fork's one name map — closed as
  the complete hidden set. Gate: `testlibcnoheaderargs` in the wine
  packed suite.
- **win64: `var_dump` of a `long` says `long(42)`** — the LLP64 platform
  `long` is a distinct 4-byte singleton type ranked dtINT32, and the
  scalar type word came from the rank, printing `int(42)`. The word now
  comes from the singleton's own source name, identical output on every
  target; LP64 provably unaffected (it never instantiates the platform
  classes). Gate: `testphpvardump`, same fixture both platforms.
- **Process: the three-platform promotion gate is codified** in
  `/promote` — assets upload only after all three lanes are built,
  verified, and green; a Windows or macOS regression blocks the
  promotion.
