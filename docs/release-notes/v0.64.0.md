# Release v0.64.0 — 2026-07-31

The four-root string/stream breakthrough. The libc++ parity lane went
747/108 → **803/80** with zero regressions at every set-diffed step —
23 tests flipped in a single commit when the `testclass` SIGSEGV proved
to be four separate compiler defects stacked on one crash address. Suite
856 → 885; the input-stream cluster's gateway is open.

- **Four roots under one crash** — the biggest single lane move of the
  campaign: unadjusted virtual-base reference arguments (madc-compiled
  stream code read `width()` out of `__precision_`, phantom-padding
  every literal and clobbering cout's precision); cast-to-reference
  ctor arguments (the spelled-out `std::forward`) scoring as `Tag*` so
  libc++'s tag-dispatch ctors never matched (+ the binding twin); the
  value-init mem-initializer on plain-struct members emitting nothing —
  every default-constructed libc++ string rep was frame garbage; and an
  untyped base-to-derived facet downcast in `use_facet`.
- **The detect-idiom chain (12 links)** — `iterator_traits<CLASS>`
  member typedefs RESOLVE, the `__is_convertible` builtin and
  [dcl.spec]/1 east-specifiers land, `__libcpp_datasizeof` folds, and
  **`vector<int>::push_back` RUNS** (out-of-line dtor definitions attach
  to template instances).
- **The `__tree`/`<map>` frontier stack** — full-spec template-id
  instantiation keys, `->` through reference-to-pointer receivers, the
  injected-class-name inside plain struct bodies, and templated
  converting ctors joining the ctor candidate set.
- **Batch-2 expression roots** — lvalue conditionals distribute
  address-of into their arms (a 22-test root), member-call heads honor
  [temp.names], literals may head expression-statements (libc++ string
  copy-assign RUNS), and aggregate reference-member arguments bind
  their referent.
- **[temp.param]p10** — template-default arguments accumulate across
  redeclarations in BOTH orders; `num_get<char>`'s default fill (the
  libc++ input-stream gateway) is unblocked.
- **15 new gate tests**, each negative-controlled against a pre-fix
  binary; a six-probe diagnostic battery ships
  (`MADC_ARITY_PROBE`, `MADC_BIND_PROBE`, `MADC_SPECREG_PROBE`,
  `MADC_ISCONV_PROBE`, `MADC_POPOP_PROBE`, `MADC_FNTPL_LOUD`).
- **One tree per source+flags** — the release battery itself caught
  object mode (`-o`/`-c`) skipping the pre-tree-build flavor-runtime
  open, so flavored native builds dropped the facet-id externs the JIT
  declared; the exe/obj lanes now build the identical tree.
- Pre-merge `/dupaudit` recorded three duplication families in the KG;
  the live divergence (`overload_arg_datadef`'s missing reference
  unwraps) is filed as task #80.
- MIR fork unchanged (`1.0-madc.0.63.0`).
