# Release v0.89.0 — 2026-08-19

`php::array_push` is ONE overloaded name that returns the new element count —
the owner's parity law implemented: php:: functions mirror the real PHP
functions; the invented `array_push_int` / `array_push_array` spellings are
retired.

- Overloads for `const char*`, `int64_t`, `double`, `bool`, `value&`,
  `std::string&`, all returning `int64_t` = the new count (PHP's
  `array_push()` return). ONE carrier overload serves `value` AND `array`
  arguments — the two spellings are the SAME DataDef (ddARRAY, one tagged
  carrier) — as a kind-preserving deep copy; pushing an array-kind carrier
  nests it.
- The motivating defect is closed by construction: `php::array_push(a, 7)`
  used to resolve the only (char*) overload and SIGSEGV at address 7; it is
  now the int-overload line of the gate test.
- New runtime plumbing `__php_array_push_real` / `_bool` / `_value`;
  `_int` / `_array` remain as plumbing (`_array` delegates to the one
  carrier implementation). The host header `ns_php.h` carries the same set
  plus a plain-`int` overload (ISO C++ would otherwise find
  `array_push(v, 7)` ambiguous). PHP's variadic multi-value form is a
  recorded parity follow-on.
- Numeric overload grading fixed one layer down (own commit, found by this
  arc's ranking probe): `score_arg_to_param` scored every mismatched numeric
  pair a flat 4, so a `float` argument picked the TRUNCATING int64 overload
  by registration order. Now graded to match what g++ and clang++ do
  unambiguously (float→double is a promotion). Gates:
  `tests/testarraypush.mad`, `tests/testoverloadnumrank.mad`.

Validation: fulltest 1093/0 (0 timeouts, 9 skips), EXE 1053/0, OBJ 1053/0,
release + packed + headerless lanes green, `--version` gate 0.89.0.
