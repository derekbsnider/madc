# Release v0.97.0 — 2026-09-01

madcide grows its interaction backbone and the dialect gets its
elegance arc. The editor now has a clean session/client seam (the
gateway architecture's first slice), a modes palette, and a real vi
modal personality — all as profile data through one key parser. On the
language side, the carrier's literal story is complete: keyed literals,
PHP's `rows[] =` append accessor, brace literals as expressions, and
subscripts that dispatch on a var index's live kind — collapsing
madcide's own row-building code by over a hundred lines.

Highlights:

- **The gateway seam (s148)**: `class IdeSession` is the session layer;
  the TUI client (`madcide_client.inc`) talks to it through the
  facts/keytable/terminal-request protocol — the first slice of the
  IDE-as-API-gateway architecture (thin clients, future GUI/MCP/LSP).
- **vi modal editing (s149)**: `profiles/neovim.keys` is a full modal
  personality — @normal/@insert scope tables, counts, operator+motion
  grammar (`2dd`, `cc`, count+G), the colon line (`:w :q :e :N !cmd`),
  showmode/showcmd — all data; a profile carrying @normal data loads
  modal, and the ^N modes palette toggles it anywhere.
- **Keyed value literals (s149b)**: `var m = { "a": 1, "b": "two" };`
  lowers through the same operator= rows as `m[key] = value`, so the
  literal and per-key spellings cannot drift.
- **The append accessor + literal expressions (s149c)**:
  `rows[] = { "act": "colon" };` — PHP's empty `[]` appends; brace
  literals work as assignment right-hand sides and call arguments
  (overload-aware: `rows.push({...})` finds `push(value&)`).
- **Live-kind subscripts (s149c)**: `m[kn]` keys when kn holds a
  string, indexes when it holds a number — closing a defect class
  where a var index's POINTER was silently coerced to an element index.
- **Parser walls**: the associative-literal hang class (a bare `:`
  spinning every caller loop) and the silent operand-juxtaposition drop
  (`{ "a" 1 }` compiled to `{ 1 }`) both refuse loudly now; the wall
  also exposed a pre-existing darwin-grove miscompile, banked with its
  baseline entry and reducer.
- **c-testsuite conformance COMPLETE (2026-08-29)**: 220/220 in C mode
  (`--std=gnu11`), baseline empty — enum tag namespace, flexible-array
  init, pointee-const identity among the closing fixes.
- **prompt-choose fix**: a prompt opened from a focused pane row could
  never commit (the engine hands enter back as a choose); prompts now
  route the choose through the same @prompt data as the enter key.
- **One args-list reader**: the three ctor-args parse loops
  (declaration, functional construction, forest flush) consolidated
  into `Program::parse_ctor_args_list`.
- Wave validation: Linux JIT 1247/0/9, EXE+OBJ 1193/0, packed 1247/0,
  headerless 1220/0; wine64 1197/0; macOS 8/3 leg-for-leg parity;
  c-testsuite 220/220.
