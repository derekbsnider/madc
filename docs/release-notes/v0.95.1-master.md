# madc v0.95.1

**This is the download release for the v0.95 line** — every feature in
the [v0.95.0 release](https://github.com/derekbsnider/madc/releases/tag/v0.95.0)
(the `ui::` namespace, Colossal Cave Adventure fully playable in madc,
the ~150 ms-class project startup, the zero-include dialect, the 2.8×
FP speedup, the community-attributed MIR hardening) ships in the
packages attached here for Linux (`.deb`/`.rpm`), Windows x86-64, and
macOS (Apple Silicon + Intel).

## The patch

- **win64: `--project` crashed at the first user-function call** — the
  v0.95.0 startup lever's lazy first-call code generation is broken at
  MIR's win64 redirect. Caught by the promotion gate's Windows suite
  before any asset shipped; win64 now keeps the eager (v0.92.1-proven)
  interface while Linux/macOS keep the startup lever. The underlying
  MIR win64 wrapper fix is the recorded follow-up.
