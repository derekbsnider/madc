# The shell

The shell (**View ▸ Shell**) runs code one entry at a time: a
declaration, a statement or an expression. An expression's value is
printed.

| Entry | What it does |
|:--|:--|
| `int x = 6 * 7;` | declares `x`, which later entries can use |
| `x + 1` | prints `43` |
| `%help` | lists the shell's commands |

Entries that start with `%` are the shell's own commands; `%help` lists
them all.

**Edit ▸ Clear shell** clears what the shell shows; the session's names
stay.

See also: [Running a program](running.md).
