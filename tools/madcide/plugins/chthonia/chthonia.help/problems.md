# Finding problems

Saving a file checks it. The problems the check finds are listed in
**View ▸ Problems**; choosing one moves the cursor to its line.

**View ▸ Outline** lists the file's definitions; choosing one moves the
cursor to it.

When the file is in a git repository, the status line shows the branch,
and a `*` when the file differs from its last commit. **View ▸ Changes**
shows those differences, **View ▸ History…** the commits that changed
the file, and **View ▸ Blame line** who last changed the cursor's line.
