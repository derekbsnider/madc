# madcide Help

madcide edits, checks, builds and runs C, C++ and madc programs. Its
menus, keys and panes come from the profile in use; this help comes
from the same place.

- [Menus and commands](menus)

Help ▸ Keyboard Help lists the loaded key style's bindings. A topic's
links are rows of their own: move to one and press Enter to open it.
